2025百度之星决赛第十题 shopping

发表于2026-08-19|更新于2026-08-19|算法
|浏览量:

题目描述

自入学起，小度就一直有一个远大的梦想——在学校附近建一所购物中心。

花落又花开，花开又花落。两年多过去了，购物中心连个影都没有。

由于小度的学校地处偏远，小度和伙伴们不得不为了购买材料而长途跋涉。同时，作为学生，大家又不得不通过“东市买骏马，西市买鞍鞯，南市买辔头，北市买长鞭”的方式来节省有限的经费。

离学校较远的地方有 NNN 家物美价廉的商店，而大家总共需要购买 MMM 件材料。在第 iii 家商店购买第 jjj 件材料的价格为 ai,ja_{i,j}ai,j​。为了购买所有材料，可以选择只在其中一家商店完成购物，也可以选择多家商店分别购买不同材料。

连接学校和商店的交通网可以看成一张有 (N+1)(N+1)(N+1) 个点、KKK 条边的无向图，其中第 iii 家商店的编号为 iii，学校的编号为 (N+1)(N+1)(N+1)；第 iii 条边连接 uiu_iui​ 和 viv_ivi​，每次经过这条边的交通成本是 wiw_iwi​。

作为领队之一，小度希望能找到一个买齐所有 MMM 件材料的方案。具体而言，小度和伙伴们需要从学校出发，按任意顺序前往选定的商店，在买齐材料后最终回到学校；在购物过程中，可以任意次途径学校。

小度希望可以最小化这个方案中购买材料的成本与交通成本的总和。

因为大家都在忙着准备月底的新歌，所以需要有人帮忙设计成本最小的方案。

输入格式

从标准输入读入数据。

输入的第一行包含三个正整数 N,M,KN,M,KN,M,K，表示可选的商店数量，需要购买的材料数量，以及交通网的边数。

保证：

1≤N≤161 \le N \le 16 1≤N≤16

1≤M≤50001 \le M \le 5000 1≤M≤5000

1≤K≤N(N+1)21 \le K \le \frac{N(N+1)}{2} 1≤K≤2N(N+1)​

接下来 NNN 行，每行输入 MMM 个正整数 ai,ja_{i,j}ai,j​，表示在每家商店购买材料的费用。

保证：

1≤ai,j≤1091 \le a_{i,j} \le 10^9 1≤ai,j​≤109

接下来 KKK 行，每行输入三个正整数 ui,vi,wiu_i,v_i,w_iui​,vi​,wi​，描述一条交通网中的边及其单次通过的交通成本。

保证：

1≤ui,vi≤N+11 \le u_i,v_i \le N+1 1≤ui​,vi​≤N+1

ui≠viu_i \ne v_i ui​​=vi​

1≤wi≤1091 \le w_i \le 10^9 1≤wi​≤109

保证输入的交通网连通且不包含重边。

输出格式

输出到标准输出。

输出一个正整数，表示买齐材料所需的最小成本。

思路

因为商店数量很小：

N≤16N\le 16 N≤16

所以可以用二进制状态 mask 表示最终去了哪些商店。

对于一个确定的商店集合 SSS，总费用可以拆成两部分：

cost(S)=buy(S)+travel(S)\text{cost}(S)=\text{buy}(S)+\text{travel}(S) cost(S)=buy(S)+travel(S)

其中：

  • buy[S]：只在集合 SSS 中的商店购买所有材料的最小费用；
  • travel[S]：从学校出发，访问完 SSS 中所有商店后回到学校的最小交通费用。

最后枚举所有非空集合：

ans=min⁡S≠∅(buy(S)+travel(S))ans=\min_{S\ne\varnothing} \left(\text{buy}(S)+\text{travel}(S)\right) ans=S​=∅min​(buy(S)+travel(S))

1. Floyd 预处理最短路

原图中两个地点之间不一定有直接道路，因此先用 Floyd 求任意两点之间的最短距离：

dis[i][j]=min⁡(dis[i][j],dis[i][k]+dis[k][j])dis[i][j]=\min(dis[i][j],dis[i][k]+dis[k][j]) dis[i][j]=min(dis[i][j],dis[i][k]+dis[k][j])

之后可以直接把 dis[i][j] 看成从地点 iii 到地点 jjj 的最小交通成本。

2. 计算每个商店集合的购买费用

假设已经确定访问集合 SSS。

对于第 jjj 件材料，肯定选择 SSS 中价格最低的商店购买：

buy(S)=∑j=1Mmin⁡i∈Sai,j\text{buy}(S)=\sum_{j=1}^{M}\min_{i\in S}a_{i,j} buy(S)=j=1∑M​i∈Smin​ai,j​

如果直接枚举所有集合、所有材料，复杂度为：

O(M2N)O(M2^N) O(M2N)

会比较大，因此需要优化。

对于一件材料，将所有商店的价格从小到大排序：

v1≤v2≤⋯≤vNv_1\le v_2\le\cdots\le v_N v1​≤v2​≤⋯≤vN​

设 PkP_kPk​ 表示价格最低的前 kkk 家商店组成的集合。

先假设这件材料花最贵的 vNv_NvN​。如果选择的商店集合 SSS 与 PkP_kPk​ 有交集，那么价格就可以减少：

vk+1−vkv_{k+1}-v_k vk+1​−vk​

因此可以把每个价格差记录到对应的前缀集合中：

w[Pk]+=vk+1−vkw[P_k]\mathrel{+}=v_{k+1}-v_k w[Pk​]+=vk+1​−vk​

同时令：

C=∑j=1Mmax⁡iai,jC=\sum_{j=1}^{M}\max_i a_{i,j} C=j=1∑M​imax​ai,j​

那么：

buy(S)=C−∑P:P∩S≠∅w[P]\text{buy}(S) = C-\sum_{P:P\cap S\ne\varnothing}w[P] buy(S)=C−P:P∩S​=∅∑​w[P]

为了快速处理“与 SSS 相交”的集合，考虑补集：

P∩S=∅  ⟺  P⊆S‾P\cap S=\varnothing \iff P\subseteq \overline S P∩S=∅⟺P⊆S

设：

W=∑Pw[P]W=\sum_Pw[P] W=P∑​w[P]

则：

buy(S)=C−W+∑P⊆S‾w[P]\text{buy}(S) = C-W+\sum_{P\subseteq\overline S}w[P] buy(S)=C−W+P⊆S∑​w[P]

于是问题变成求所有集合的子集和。

使用 SOS DP：

f[T]=∑P⊆Tw[P]f[T]=\sum_{P\subseteq T}w[P] f[T]=P⊆T∑​w[P]

最终：

buy(S)=C−W+f[S‾]\boxed{ \text{buy}(S)=C-W+f[\overline S] } buy(S)=C−W+f[S]​

这样就能在 O(1)O(1)O(1) 时间得到每个集合的购买费用。

3. 状压 DP 计算交通费用

定义：

dp[S][i]dp[S][i] dp[S][i]

表示：

从学校出发，已经访问集合 SSS 中的所有商店，当前停在商店 iii 的最小交通费用。

初始化：

dp[i][i]=dis[school][i]dp[{i}][i]=dis[school][i] dp[i][i]=dis[school][i]

转移：

如果当前在商店 iii，接下来前往一个还没有访问过的商店 jjj：

dp[S∪j][j]=min⁡(dp[S∪j][j],dp[S][i]+dis[i][j])dp[S\cup{j}][j] = \min \left( dp[S\cup{j}][j], dp[S][i]+dis[i][j] \right) dp[S∪j][j]=min(dp[S∪j][j],dp[S][i]+dis[i][j])

访问完集合 SSS 后还需要回到学校，因此：

travel(S)=min⁡i∈S(dp[S][i]+dis[i][school])\text{travel}(S) = \min_{i\in S} \left( dp[S][i]+dis[i][school] \right) travel(S)=i∈Smin​(dp[S][i]+dis[i][school])

4. 合并答案

最后枚举所有非空商店集合 SSS：

ans=min⁡S≠∅(buy(S)+travel(S))\boxed{ ans= \min_{S\ne\varnothing} \left( \text{buy}(S)+\text{travel}(S) \right) } ans=S​=∅min​(buy(S)+travel(S))​

整体复杂度为：

O(MNlog⁡N+N22N)O(MN\log N+N^2 2^N) O(MNlogN+N22N)

其中 N≤16N\le16N≤16，可以通过。
