Game

题目描述

坐标轴上有 nnn 枚棋子，初始坐标分别为

1,2,…,n1,2,\dots,n 1,2,…,n

你可以任选一枚棋子，并让它向前（即增大坐标）跳到一个没有棋子的任意整数坐标上，称为一次操作。

每次操作前，记当前有棋子的最小坐标为 xxx，那么你需要保证：此次操作后，所有棋子的坐标均不超过

x+dx+d x+d

当有一枚棋子的坐标不小于 lll 时，游戏立即终止。

求你能进行的最少和最多的操作次数。

输入格式

从标准输入读入数据。

第一行一个整数 TTT：

1≤T≤1051\le T\le 10^5 1≤T≤105

表示测试数据组数。

对于每组测试数据，一行三个整数 n,d,ln,d,ln,d,l：

2≤n≤d≤l≤109,n<l2\le n\le d\le l\le 10^9,\qquad n<l 2≤n≤d≤l≤109,n<l

输出格式

输出到标准输出。

对于每组测试数据，输出一行两个整数，分别表示你能进行的最少操作次数和最多操作次数。

思路

最少操作次数

若当前最小坐标为 xxx，想在下一次操作中直接跳到 lll，必须满足

x+d≥lx+d\ge l x+d≥l

也就是

x≥l−dx\ge l-d x≥l−d

因此，需要先让所有棋子的坐标都不小于 l−dl-dl−d，最后再用一次操作跳到 lll。

令

X=l−d−1X=l-d-1 X=l−d−1

那么所有不超过 XXX 的位置都需要被移动一次。

由于 n≤dn\le dn≤d，这些位置可以按层划分：

1,2,…,n1,2,\ldots,n 1,2,…,n

d+1,d+2,…,d+nd+1,d+2,\ldots,d+n d+1,d+2,…,d+n

2d+1,2d+2,…,2d+n2d+1,2d+2,\ldots,2d+n 2d+1,2d+2,…,2d+n

完整层数为

⌊Xd⌋\left\lfloor\frac{X}{d}\right\rfloor ⌊dX​⌋

每层有 nnn 个位置，最后一层有

min⁡(n,X mod d)\min(n,X\bmod d) min(n,Xmodd)

个位置。

所以最少操作次数为

ansmin⁡=⌊Xd⌋n+min⁡(n,X mod d)+1ans_{\min} = \left\lfloor\frac{X}{d}\right\rfloor n +\min(n,X\bmod d)+1 ansmin​=⌊dX​⌋n+min(n,Xmodd)+1

其中最后的 111 表示跳到 lll 的终止操作。

最多操作次数

为了让操作次数尽可能多，每次让棋子的坐标只增加 111。

游戏结束前，所有棋子坐标都必须小于 lll。此时坐标和最大的状态为

l−n,l−n+1,…,l−1l-n,l-n+1,\ldots,l-1 l−n,l−n+1,…,l−1

初始状态为

1,2,…,n1,2,\ldots,n 1,2,…,n

两者坐标和之差为

n(l−n−1)n(l-n-1) n(l−n−1)

由于每次操作坐标和至少增加 111，终止前最多进行 n(l−n−1)n(l-n-1)n(l−n−1) 次操作。

最后再进行一次操作跳到 lll，因此

ansmax⁡=n(l−n−1)+1ans_{\max}=n(l-n-1)+1 ansmax​=n(l−n−1)+1

Degree of Permutations

题目描述

给定两个长度为 nnn 的序列：

a1,a2,…,ana_1,a_2,\dots,a_n a1​,a2​,…,an​

和

b1,b2,…,bnb_1,b_2,\dots,b_n b1​,b2​,…,bn​

对于一个 1∼n1\sim n1∼n 的排列 ppp，以及其第 xxx 个位置，其中：

1<x≤n1<x\le n 1<x≤n

若满足：

apx=∑i=1x−1bpia_{p_x}=\sum_{i=1}^{x-1} b_{p_i} apx​​=i=1∑x−1​bpi​​

则称第 xxx 个位置是好的，否则称为不好的。

定义一个排列的度为其好的位置的数量。

问所有 1∼n1\sim n1∼n 的排列的度之和是多少。

由于答案可能很大，请对：

109+710^9+7 109+7

取模。

输入格式

从标准输入读入数据。

第一行一个整数 nnn：

1≤n≤2001\le n\le 200 1≤n≤200

第二行输入 nnn 个整数：

a1,a2,…,ana_1,a_2,\dots,a_n a1​,a2​,…,an​

其中：

1≤ai≤1091\le a_i\le 10^9 1≤ai​≤109

第三行输入 nnn 个整数：

b1,b2,…,bnb_1,b_2,\dots,b_n b1​,b2​,…,bn​

其中：

1≤bi≤1001\le b_i\le 100 1≤bi​≤100

输出格式

输出到标准输出。

输出一个整数，表示所有排列的度之和对：

109+710^9+7 109+7

取模后的结果。

思路

固定排列中第 xxx 个位置的元素为 jjj，令：

k=x−1k=x-1 k=x−1

那么这个位置是好的，当且仅当它前面的 kkk 个元素满足：

∑bi=aj\sum b_i=a_j ∑bi​=aj​

所以问题转化为：

从除 jjj 以外的元素中选择 kkk 个，使它们的 bbb 之和为 aja_jaj​。

若某个合法前缀集合大小为 kkk，那么：

  • 前面 kkk 个元素有 k!k!k! 种排列；
  • 后面剩余 n−k−1n-k-1n−k−1 个元素有 (n−k−1)!(n-k-1)!(n−k−1)! 种排列。

因此一个合法集合贡献：

k!(n−k−1)!k!(n-k-1)! k!(n−k−1)!

定义：

f[k][s]f[k][s] f[k][s]

表示从全部元素中选 kkk 个，且 bbb 之和为 sss 的方案数，用 01 背包求出。

但前缀中不能选到当前元素 jjj，所以设：

gj[k][s]g_j[k][s] gj​[k][s]

表示不选 jjj 时的方案数。

有：

f[k][s]=gj[k][s]+gj[k−1][s−bj]f[k][s] = g_j[k][s]+g_j[k-1][s-b_j] f[k][s]=gj​[k][s]+gj​[k−1][s−bj​]

因此：

gj[k][s]=f[k][s]−f[k−1][s−bj]+f[k−2][s−2bj]−⋯g_j[k][s] = f[k][s]-f[k-1][s-b_j]+f[k-2][s-2b_j]-\cdots gj​[k][s]=f[k][s]−f[k−1][s−bj​]+f[k−2][s−2bj​]−⋯

对于每个 j,kj,kj,k，取 s=ajs=a_js=aj​，得到合法前缀集合数，再乘：

k!(n−k−1)!k!(n-k-1)! k!(n−k−1)!

累加即可。

最终答案：

∑j=1n∑k=1n−1gj[k][aj]⋅k!⋅(n−k−1)!\boxed{ \sum_{j=1}^{n} \sum_{k=1}^{n-1} g_j[k][a_j]\cdot k!\cdot(n-k-1)! } j=1∑n​k=1∑n−1​gj​[k][aj​]⋅k!⋅(n−k−1)!​
