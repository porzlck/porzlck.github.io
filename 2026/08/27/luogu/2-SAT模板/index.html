2-SAT模板

发表于2026-08-27|更新于2026-08-27|算法
|浏览量:

题目描述

有 nnn 个布尔变量 x1∼xnx_1\sim x_nx1​∼xn​，另有 mmm 个需要满足的条件，每个条件的形式都是 「xix_ixi​ 为 true / false 或 xjx_jxj​ 为 true / false」。比如 「x1x_1x1​ 为真或 x3x_3x3​ 为假」、「x7x_7x7​ 为假或 x2x_2x2​ 为假」。

2-SAT 问题的目标是给每个变量赋值使得所有条件得到满足。

输入格式

第一行两个整数 nnn 和 mmm，意义如题面所述。

接下来 mmm 行每行 444 个整数 iii, aaa, jjj, bbb，表示 「xix_ixi​ 为 aaa 或 xjx_jxj​ 为 bbb」(a,b∈{0,1}a, b\in \{0,1\}a,b∈{0,1})

输出格式

如无解，输出 IMPOSSIBLE；

否则输出 POSSIBLE，下一行 nnn 个整数 x1∼xnx_1\sim x_nx1​∼xn​（xi∈{0,1}x_i\in\{0,1\}xi​∈{0,1}），表示构造出的解。

说明/提示

1≤n,m≤1061\leq n, m\leq 10^61≤n,m≤106 , 前 333 个点卡小错误，后面 555 个点卡效率。

由于数据随机生成，可能会含有 10 0 10 0 之类的坑，但按照最常规写法的写的标程没有出错，各个数据点卡什么的提示在标程里。

思路

对于每个变量 xix_ixi​，建立两个点：

  • iii：表示 xi=1x_i=1xi​=1
  • i+ni+ni+n：表示 xi=0x_i=0xi​=0

所以整张图一共有 2n2n2n 个点。

对于一个限制：

(xi=a)∨(xj=b)(x_i=a)\lor(x_j=b) (xi​=a)∨(xj​=b)

利用：

A∨B  ⟺  (¬A→B)∧(¬B→A)A\lor B\iff (\neg A\to B)\land(\neg B\to A) A∨B⟺(¬A→B)∧(¬B→A)

可以将一个“或”条件转化成两条蕴含边。

也就是说：

如果一边不成立，那么另一边必须成立。

四种情况分别为：

xi∨xjx_i\lor x_j xi​∨xj​

建边：

¬xi→xj\neg x_i\to x_j ¬xi​→xj​

¬xj→xi\neg x_j\to x_i ¬xj​→xi​

¬xi∨xj\neg x_i\lor x_j ¬xi​∨xj​

xi→xjx_i\to x_j xi​→xj​

¬xj→¬xi\neg x_j\to\neg x_i ¬xj​→¬xi​

xi∨¬xjx_i\lor\neg x_j xi​∨¬xj​

¬xi→¬xj\neg x_i\to\neg x_j ¬xi​→¬xj​

xj→xix_j\to x_i xj​→xi​

¬xi∨¬xj\neg x_i\lor\neg x_j ¬xi​∨¬xj​

xi→¬xjx_i\to\neg x_j xi​→¬xj​

xj→¬xix_j\to\neg x_i xj​→¬xi​

建完图后，使用 Tarjan 求强连通分量。

图中的一条边 A→BA\to BA→B 表示：如果状态 AAA 成立，那么状态 BBB 也必须成立。因此如果 xix_ixi​ 和 ¬xi\neg x_i¬xi​ 位于同一个强连通分量中，就说明：

xi⇝¬xix_i\leadsto\neg x_i xi​⇝¬xi​

并且：

¬xi⇝xi\neg x_i\leadsto x_i ¬xi​⇝xi​

也就是说，无论 xix_ixi​ 取 000 还是 111，都会被推出相反状态，因此一定无解。

所以若存在：

coli=coli+ncol_i=col_{i+n} coli​=coli+n​

则输出 IMPOSSIBLE。

否则一定有解。

Tarjan 在强连通分量出栈时编号，因此得到的是缩点图的反拓扑序。对于本代码的编号方式，编号越小表示越早出栈，所以对于每个变量：

coli<coli+ncol_i<col_{i+n} coli​<coli+n​

时令：

xi=1x_i=1 xi​=1

否则令：

xi=0x_i=0 xi​=0

总时间复杂度为：

O(n+m)O(n+m) O(n+m)
