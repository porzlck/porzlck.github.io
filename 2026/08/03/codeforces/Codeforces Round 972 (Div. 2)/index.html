CF2005C Lazy Narek

题目描述

Alice\text{Alice}Alice 有 nnn 个字符串，每个字符串长度为 mmm。

Alice\text{Alice}Alice 会选择 nnn 个字符串的一个子集，可以为空，将子集中的字符串首尾按原本的相对顺序拼接，然后她会在拼接的字符串中依次查找字符 “n”,“a”,“r”,“e”,“k”。当这五个字符全被找到后，Alice\text{Alice}Alice 会将自己的分数 +5+5+5 然后继续从当前位置向后查找。

之后 Bob\text{Bob}Bob 会扫描整个字符串并查找，如果 Alice\text{Alice}Alice 的查找中有未被访问的 “n”,“a”,“r”,“e” 或 “k”，Bob\text{Bob}Bob 会将自己的分数 +1+1+1。

请你帮 Alice\text{Alice}Alice 和 Bob\text{Bob}Bob 求出 max⁡{scoreAlice−scoreBob}\max\{score_{Alice} - score_{Bob}\}max{scoreAlice​−scoreBob​}。

输入格式

多组测试数据，第一行一个正整数 T(1≤T≤105)T(1 \leq T \leq 10^5)T(1≤T≤105)，表示数据组数。

接下来每个测试数据的第一行两个正整数 n,m(1≤n,m≤103)n,m(1 \leq n,m \leq 10^3)n,m(1≤n,m≤103)，表示字符串的数量以及每个字符串的长度。

接下来 nnn 行，每行一个长度为 mmm 的字符串，意义如题意所述，仅包含小写字母。

∑n⋅m≤106\sum{n \cdot m} \leq 10^6∑n⋅m≤106

输出格式

对于每个测试数据，输出一个整数：scoreAlice−scoreBobscore_{Alice} - score_{Bob}scoreAlice​−scoreBob​ 的最大值

CF2005D Alter the GCD

题目描述

给定两个数组 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​ 和 b1,b2,…,bnb_1, b_2, \ldots, b_nb1​,b2​,…,bn​。

你必须恰好执行一次如下操作：

  • 选择任意下标 lll 和 rrr，满足 1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n；
  • 对所有满足 l≤i≤rl \leq i \leq rl≤i≤r 的 iii，交换 aia_iai​ 和 bib_ibi​。

请你在恰好执行一次操作后，求 gcd⁡(a1,a2,…,an)+gcd⁡(b1,b2,…,bn)\gcd(a_1, a_2, \ldots, a_n) + \gcd(b_1, b_2, \ldots, b_n)gcd(a1​,a2​,…,an​)+gcd(b1​,b2​,…,bn​) 的最大可能值，并统计有多少不同的 (l,r)(l, r)(l,r) 对能够达到最大值。

输入格式

输入的第一行包含一个整数 ttt（1≤t≤1051 \le t \le 10^51≤t≤105），表示测试用例的数量。接下来是每个测试用例的描述。

每个测试用例的第一行包含一个整数 nnn（1≤n≤2⋅1051 \le n \le 2 \cdot 10^51≤n≤2⋅105），表示每个数组中的元素个数。

接下来一行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​（1≤ai≤1091 \le a_i \le 10^91≤ai​≤109），表示数组 aaa 的元素。

最后一行包含 nnn 个整数 b1,b2,…,bnb_1, b_2, \ldots, b_nb1​,b2​,…,bn​（1≤bi≤1091 \le b_i \le 10^91≤bi​≤109），表示数组 bbb 的元素。

所有测试用例中 nnn 的总和不超过 5⋅1055 \cdot 10^55⋅105。

输出格式

对于每个测试用例，输出一行两个整数，分别表示在恰好执行一次操作后，gcd⁡(a1,a2,…,an)+gcd⁡(b1,b2,…,bn)\gcd(a_1, a_2, \ldots, a_n) + \gcd(b_1, b_2, \ldots, b_n)gcd(a1​,a2​,…,an​)+gcd(b1​,b2​,…,bn​) 的最大值，以及达到最大值的 (l,r)(l, r)(l,r) 对的数量。

CF2005E1 Subtangle Game (Easy Version)

题目描述

这是问题的简单版本。两个版本的区别在于所有变量的约束。只有当两个版本的问题都解决时，才能进行 Hack。

Tsovak 和 Narek 正在玩一个游戏。他们有一个整数数组 aaa 和一个整数矩阵 bbb，矩阵有 nnn 行 mmm 列，行列编号从 1 开始。矩阵中第 iii 行第 jjj 列的单元格为 $ (i, j) $。

他们轮流在矩阵中寻找数组 aaa 的元素；Tsovak 先开始。每次轮到玩家时，玩家需要在矩阵中寻找当前数组 aaa 中的元素（Tsovak 寻找第一个，Narek 寻找第二个，依此类推）。假设某个玩家选择了单元格 $ (r, c) $。下一个玩家必须在从 $ (r + 1, c + 1) $ 开始、以 $ (n, m) $ 结束的子矩阵中选择他的单元格（如果 r=nr = nr=n 或 c=mc = mc=m，子矩阵可能为空）。如果某个玩家无法在这样的子矩阵中找到相应的单元格（或者剩余的子矩阵为空），或者数组已经结束（前一个玩家已经找到了最后一个元素），那么他就输了。

你的任务是确定如果两位玩家都进行最优策略时，谁会获胜。

输入格式

输入的第一行包含一个整数 ttt ( 1≤t≤3001 \le t \le 3001≤t≤300 ) —— 测试用例的数量。

每个测试用例的第一行包含三个整数 lll 、nnn 和 mmm ( 1≤l,n,m≤3001 \le l, n, m \le 3001≤l,n,m≤300 ) —— 数组的大小以及矩阵的行数和列数。

第二行包含 lll 个整数 a1,a2,a3,…ala_1, a_2, a_3, \ldots a_la1​,a2​,a3​,…al​ ( 1≤ai≤min⁡(7,n⋅m)1 \le a_i \le \min(7, n \cdot m)1≤ai​≤min(7,n⋅m) ) —— 数组 aaa 的元素。

接下来的 nnn 行中，每一行包含 mmm 个整数 bi,1,bi,2,bi,3,…bi,mb_{i,1}, b_{i,2}, b_{i,3}, \ldots b_{i,m}bi,1​,bi,2​,bi,3​,…bi,m​ ( 1≤bi,j≤min⁡(7,n⋅m)1 \le b_{i,j} \le \min(7, n \cdot m)1≤bi,j​≤min(7,n⋅m) ) —— 表示矩阵的第 iii 行。

保证所有测试用例中 n⋅mn \cdot mn⋅m 的总和不超过 10510^5105 。

保证所有测试用例中 lll 的总和不超过 300300300 。

输出格式

输出 ttt 行，每行对应一个测试用例的答案，若 Tsovak 获胜则输出 “T”，否则输出 “N”（不带引号）。
