CSP-S 2019 树的重心

发表于2026-08-26|更新于2026-08-26|算法
|浏览量:

题目描述

小简单正在学习离散数学，今天的内容是图论基础，在课上他做了如下两条笔记：

  1. 一个大小为 nnn 的树由 nnn 个结点与 n−1n - 1n−1 条无向边构成，且满足任意两个结点间有且仅有一条简单路径。在树中删去一个结点及与它关联的边，树将分裂为若干个子树；而在树中删去一条边（保留关联结点，下同），树将分裂为恰好两个子树。
  2. 对于一个大小为 nnn 的树与任意一个树中结点 ccc，称 ccc 是该树的重心当且仅当在树中删去 ccc 及与它关联的边后，分裂出的所有子树的大小均不超过 ⌊n2⌋\lfloor \frac{n}{2} \rfloor⌊2n​⌋（其中 ⌊x⌋\lfloor x \rfloor⌊x⌋ 是下取整函数）。对于包含至少一个结点的树，它的重心只可能有 1 或 2 个。

课后老师给出了一个大小为 nnn 的树 SSS，树中结点从 1∼n1 \sim n1∼n 编号。小简单的课后作业是求出 SSS 单独删去每条边后，分裂出的两个子树的重心编号和之和。即：

∑(u,v)∈E(∑1≤x≤n且x号点是Su′的重心x+∑1≤y≤n且y号点是Sv′的重心y)\sum_{(u,v) \in E} \left( \sum_{1 \leq x \leq n \atop 且 x 号点是 S'_u 的重心} x + \sum_{1 \leq y \leq n \atop 且 y 号点是 S'_v 的重心} y \right) (u,v)∈E∑​​且x号点是Su′​的重心1≤x≤n​∑​x+且y号点是Sv′​的重心1≤y≤n​∑​y​

上式中，EEE 表示树 SSS 的边集，(u,v)(u,v)(u,v) 表示一条连接 uuu 号点和 vvv 号点的边。Su′S'_uSu′​ 与 Sv′S'_vSv′​ 分别表示树 SSS 删去边 (u,v)(u,v)(u,v) 后，uuu 号点与 vvv 号点所在的被分裂出的子树。

小简单觉得作业并不简单，只好向你求助，请你教教他。

思路

考虑反过来枚举每个点 xxx，统计有多少次删边后，xxx 会成为所在连通块的重心。

先求出原树的一个重心 rtrtrt，再以 rtrtrt 为根重新 DFS。

记：

  • s[x]s[x]s[x]：xxx 的子树大小；
  • g[x]g[x]g[x]：xxx 的所有儿子子树大小的最大值。

由于 rtrtrt 是整棵树的重心，所以对任意 x≠rtx\neq rtx=rt，都有

s[x]≤n2.s[x]\le \frac n2. s[x]≤2n​.

假设删边后，包含 xxx 的连通块大小为 mmm，并且删边不在 xxx 的子树内部。

删掉 xxx 后：

  • 向下最大的连通块大小为 g[x]g[x]g[x]；
  • 向父亲方向的连通块大小为 m−s[x]m-s[x]m−s[x]。

因此 xxx 是重心当且仅当

g[x]≤m2,m−s[x]≤m2.g[x]\le \frac m2,\qquad m-s[x]\le\frac m2. g[x]≤2m​,m−s[x]≤2m​.

整理得

2g[x]≤m≤2s[x].2g[x]\le m\le 2s[x]. 2g[x]≤m≤2s[x].

令

q=n−m,q=n-m, q=n−m,

则条件变为

n−2s[x]≤q≤n−2g[x].n-2s[x]\le q\le n-2g[x]. n−2s[x]≤q≤n−2g[x].

所以问题变成：对每个 xxx，统计有多少个合法的 qqq 落在这个区间中，可以用树状数组维护。

对于一条边 (fa[y],y)(fa[y],y)(fa[y],y)：

  • 若 yyy 是 xxx 的祖先，则删边后包含 xxx 的连通块大小为 s[y]s[y]s[y]，所以

q=n−s[y].q=n-s[y]. q=n−s[y].

  • 若 x,yx,yx,y 位于不同分支，则包含 xxx 的连通块大小为 n−s[y]n-s[y]n−s[y]，所以

q=s[y].q=s[y]. q=s[y].

  • 若 yyy 在 xxx 的子树内，则这种删边下 x≠rtx\neq rtx=rt 不可能成为重心，因此需要排除。

用两棵树状数组维护这些值。

c1c1c1 初始加入所有 s[y]s[y]s[y]。DFS 从父亲 fff 走到儿子 xxx 时，将祖先链上的状态修正：

s[f]→n−s[x].s[f]\rightarrow n-s[x]. s[f]→n−s[x].

即：

这样 c1c1c1 中祖先对应的是 n−s[y]n-s[y]n−s[y]，其他分支对应的是 s[y]s[y]s[y]。

但 c1c1c1 中还包含当前 xxx 子树内部的 s[y]s[y]s[y]，这些需要删除。

c2c2c2 记录 DFS 已经访问过的所有 s[y]s[y]s[y]，并且不回滚。进入 xxx 子树前查询一次，遍历完整个 xxx 子树后再查询一次，两次查询之差正好就是 xxx 子树中新加入的部分，因此可以将其从 c1c1c1 的统计中扣掉。

于是对于 x≠rtx\neq rtx=rt，其贡献就是满足

n−2s[x]≤q≤n−2g[x]n-2s[x]\le q\le n-2g[x] n−2s[x]≤q≤n−2g[x]

的合法删边数乘上节点编号 xxx。

rtrtrt 需要单独处理，因为它没有父亲方向，不能直接套上面的式子。

设 u,vu,vu,v 分别为 rtrtrt 最大和第二大的儿子子树，并用 z[x]z[x]z[x] 表示 xxx 是否位于最大分支 uuu 中。

删除边 (fa[x],x)(fa[x],x)(fa[x],x) 后，包含 rtrtrt 的连通块大小为

n−s[x].n-s[x]. n−s[x].

若 xxx 不在最大分支 uuu 中，则最大分支 uuu 不受影响，需要满足

s[u]≤n−s[x]2.s[u]\le \frac{n-s[x]}2. s[u]≤2n−s[x]​.

若 xxx 位于最大分支 uuu 中，则 uuu 被削小，而其剩余部分一定不会超过新树的一半，只需检查原来的第二大分支 vvv：

s[v]≤n−s[x]2.s[v]\le \frac{n-s[x]}2. s[v]≤2n−s[x]​.

统一写成

s[x]≤n−2s[z[x]?v:u].s[x]\le n-2s[z[x]?v:u]. s[x]≤n−2s[z[x]?v:u].

若成立，则删掉 (fa[x],x)(fa[x],x)(fa[x],x) 后，包含 rtrtrt 的那一侧仍以 rtrtrt 为重心，答案加上 rtrtrt。
