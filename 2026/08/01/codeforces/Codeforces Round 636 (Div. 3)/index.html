CF1343E Weights Distributing

题目描述

给定一个无向无权图，包含 nnn 个顶点和 mmm 条边（代表 Bertown 的地图），以及一个长度为 mmm 的价格数组 ppp。保证任意两点之间都存在路径。

Mike 计划从顶点（区域）aaa 出发到顶点（区域）bbb，然后从顶点（区域）bbb 到顶点（区域）ccc。他可以多次经过同一个区域。但是有一个问题：城市当局想要为每条道路设置一个价格，每当有人经过一条道路时，都需要支付该道路对应的价格（每经过一次都要付费）。价格列表 ppp 已经准备好，他们只需要将其分配给城镇中的所有道路，使得每个价格恰好对应一条道路。

你是 Mike 的好朋友（同时也是 Bertown 的市长），你想帮助他让这次旅行的花费尽可能少。因此，你的任务是分配道路的价格，使得 Mike 选择最优路径时，这次旅行的总花费最小。注意，旅行开始后不能再重新分配价格。

你需要回答 ttt 个独立的测试用例。

输入格式

输入的第一行包含一个整数 ttt（1≤t≤1041 \le t \le 10^41≤t≤104），表示测试用例的数量。接下来是 ttt 个测试用例。

每个测试用例的第一行包含五个整数 n,m,a,b,cn, m, a, b, cn,m,a,b,c（2≤n≤2×1052 \le n \le 2 \times 10^52≤n≤2×105，n−1≤m≤min⁡(n(n−1)2,2×105)n-1 \le m \le \min(\frac{n(n-1)}{2}, 2 \times 10^5)n−1≤m≤min(2n(n−1)​,2×105)，1≤a,b,c≤n1 \le a, b, c \le n1≤a,b,c≤n），分别表示顶点数、边数，以及 Mike 旅行经过的区域编号。

测试用例的第二行包含 mmm 个整数 p1,p2,…,pmp_1, p_2, \dots, p_mp1​,p2​,…,pm​（1≤pi≤1091 \le p_i \le 10^91≤pi​≤109），表示价格数组中的每个价格。

接下来的 mmm 行，每行包含两个整数 vi,uiv_i, u_ivi​,ui​（1≤vi,ui≤n1 \le v_i, u_i \le n1≤vi​,ui​≤n，ui≠viu_i \ne v_iui​​=vi​），表示一条连接 viv_ivi​ 和 uiu_iui​ 的边。图中没有自环和重边，即对于每对 (vi,ui)(v_i, u_i)(vi​,ui​)，不存在其他的 (vi,ui)(v_i, u_i)(vi​,ui​) 或 (ui,vi)(u_i, v_i)(ui​,vi​)，并且 vi≠uiv_i \ne u_ivi​​=ui​。保证给定的图是连通的。

保证所有测试用例中 nnn 的总和不超过 2×1052 \times 10^52×105，mmm 的总和也不超过 2×1052 \times 10^52×105（∑n≤2×105\sum n \le 2 \times 10^5∑n≤2×105，∑m≤2×105\sum m \le 2 \times 10^5∑m≤2×105）。

输出格式

对于每个测试用例，输出一个整数，表示在最优分配价格的情况下，Mike 这次旅行的最小可能花费。

思路

枚举一个中间汇合点 iii，将整条路线看成：

a→i→b→i→ca \rightarrow i \rightarrow b \rightarrow i \rightarrow ca→i→b→i→c

分别从 a,b,ca,b,ca,b,c 出发进行 BFS，得到：

da[i]d_a[i]da​[i]：aaa 到 iii 的最短距离；

db[i]d_b[i]db​[i]：bbb 到 iii 的最短距离；

dc[i]d_c[i]dc​[i]：ccc 到 iii 的最短距离。

对于汇合点 iii，三段路径总共使用的边数为：

da[i]+db[i]+dc[i]d_a[i]+d_b[i]+d_c[i]da​[i]+db​[i]+dc​[i]

其中 bbb 到 iii 的这一段会被经过两次，因此这部分价格需要额外支付一次。

先将所有价格从小到大排序，并求前缀和：

pre[i]=p1+p2+⋯+pipre[i]=p_1+p_2+\cdots+p_ipre[i]=p1​+p2​+⋯+pi​

为了使总费用最小，应把最便宜的价格分配给经过两次的边。

因此，当汇合点为 iii 时，总费用为：

pre[da[i]+db[i]+dc[i]]+pre[db[i]]pre[d_a[i]+d_b[i]+d_c[i]]+pre[d_b[i]]pre[da​[i]+db​[i]+dc​[i]]+pre[db​[i]]

其中必须满足：

da[i]+db[i]+dc[i]≤md_a[i]+d_b[i]+d_c[i]\le mda​[i]+db​[i]+dc​[i]≤m

枚举所有顶点 iii，取上述费用的最小值即可。

CF1343F Restore the Permutation by Sorted Segments

题目描述

我们猜测了一个由 nnn 个整数组成的排列 ppp。长度为 nnn 的排列是指长度为 nnn 的数组，其中每个 111 到 nnn 的元素恰好出现一次。这个排列对你来说是一个秘密。

对于每个位置 rrr，其中 2≤r≤n2 \le r \le n2≤r≤n，我们选择了另一个下标 lll（l<rl < rl<r），并将区间 pl,pl+1,…,prp_l, p_{l + 1}, \dots, p_rpl​,pl+1​,…,pr​ 按升序排列后给你（即我们将该区间的元素重新排列，使其有序）。因此，你总共得到了初始排列的 n−1n-1n−1 个区间，但每个区间内的元素都是有序的。这些区间的顺序是随机的。

例如，如果秘密排列为 p=[3,1,4,6,2,5]p=[3, 1, 4, 6, 2, 5]p=[3,1,4,6,2,5]，那么可能给出的区间集合为：

  • [2,5,6][2, 5, 6][2,5,6]
  • [4,6][4, 6][4,6]
  • [1,3,4][1, 3, 4][1,3,4]
  • [1,3][1, 3][1,3]
  • [1,2,4,6][1, 2, 4, 6][1,2,4,6]

你的任务是找出任意一个符合条件的排列（即，任意一个与给定输入数据对应的排列）。保证输入数据一定对应某个排列（即一定存在这样的排列）。

你需要回答 ttt 组独立的测试用例。

输入格式

输入的第一行包含一个整数 ttt（1≤t≤1001 \le t \le 1001≤t≤100），表示测试用例的数量。接下来是 ttt 组测试用例。

每组测试用例的第一行包含一个整数 nnn（2≤n≤2002 \le n \le 2002≤n≤200），表示排列的长度。

接下来的 n−1n-1n−1 行描述给定的区间。

第 iii 行以一个整数 kik_iki​（2≤ki≤n2 \le k_i \le n2≤ki​≤n）开头，表示第 iii 个区间的长度。接下来有 kik_iki​ 个整数，均为升序排列，且在 111 到 nnn 之间，且在该行内互不相同。

保证对于每个测试用例都存在所需的排列。

还保证所有测试用例中 nnn 的总和不超过 200200200（∑n≤200\sum n \le 200∑n≤200）。

输出格式

对于每个测试用例，输出一行答案：nnn 个整数 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​（1≤pi≤n1 \le p_i \le n1≤pi​≤n，所有 pip_ipi​ 互不相同），即任意一个符合条件的排列。
