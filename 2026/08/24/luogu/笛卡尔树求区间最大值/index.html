题目要求请阅读下方输入格式。

输入格式

给你一个随机数生成器

读入三个数 n,m,sn,m,sn,m,s。

首先你需要 srand(s) 一下。

然后 nnn 个数表示序列 aia_iai​，这个直接调用 read 函数

然后 mmm 个询问，询问区间最大值，询问的区间是 l=read() mod n+1,r=read() mod n+1l = \text{read()} \bmod n + 1 , r = \text{read()} \bmod n + 1l=read()modn+1,r=read()modn+1。注意有可能 l>rl > rl>r，此时需要交换 l,rl,rl,r。

输出格式

输出一个 unsigned long long 类型的整数表示每次询问的答案的和。
