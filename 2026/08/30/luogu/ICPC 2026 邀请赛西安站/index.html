E

题目描述

ICPC 2026 长安邀请赛即将开赛。现有 nnn 支队伍打算报名比赛，其中第 iii 支队伍会在第 viv_ivi​ 秒时访问报名网页。

对于所有正整数 sss：

  • 若在第 sss 秒时访问报名网页的队伍数量不超过 xxx，则所有在第 sss 秒时访问报名网页的队伍报名成功。
  • 否则，报名网页会因为太多队伍访问而在这一秒崩溃，所有在第 sss 秒时访问报名网页的队伍报名失败。

作为 ICPC 2026 长安邀请赛的裁判长，Yuki 想要知道这场比赛的报名情况。因此，你需要帮助她计算报名成功的队伍数量。

输入格式

本题包含多组测试数据。

第一行包含一个正整数 ttt (1≤t≤105)(1 \le t \le 10^5)(1≤t≤105)，表示测试数据组数。

对于每组测试数据：

  • 第一行包含两个正整数 n,xn, xn,x (1≤n≤2⋅105, 1≤x≤n)(1 \le n \le 2\cdot10^5,\ 1 \le x \le n)(1≤n≤2⋅105, 1≤x≤n)。
  • 第二行包含 nnn 个正整数 v1,…,vnv_1, \dots, v_nv1​,…,vn​ (1≤vi≤109)(1 \le v_i \le 10^9)(1≤vi​≤109)。

保证所有测试数据中 nnn 的总和不超过 2⋅1052\cdot10^52⋅105。

输出格式

对于每组测试数据，输出一行，包含一个整数，表示报名成功的队伍数量。

思路

按照题意写即可。

D

题目描述

Yuki 在玩一款叫做 Qenerals 的游戏。

第 000 秒时，Yuki 拥有的士兵数量 x=0x = 0x=0，占领的堡垒数量 y=1y = 1y=1。地图上还有 nnn 个未被占领的堡垒，第 iii 个堡垒的参数为 aia_iai​。

游戏一共会进行 mmm 秒。对于每个不大于 mmm 的正整数 iii：

  • 在第 iii 秒开始时，每个 Yuki 所占领的堡垒都会为 Yuki 生产 111 个士兵，即 x←x+yx \leftarrow x + yx←x+y。
  • 在第 iii 秒结束时，Yuki 可以进行任意次操作（可以为 000 次）；每次操作，Yuki 需要选择一个未被占领的堡垒 jjj 满足 aj≤xa_j \le xaj​≤x，接着消耗 aja_jaj​ 个士兵并占领第 jjj 个堡垒，即 x←x−ajx \leftarrow x - a_jx←x−aj​ 且 y←y+1y \leftarrow y + 1y←y+1。

你需要帮助 Yuki 求出，在游戏结束后，她最多能拥有多少个士兵。

输入格式

本题包含多组测试数据。

第一行包含一个正整数 ttt (1≤t≤105)(1 \le t \le 10^5)(1≤t≤105)，表示测试数据组数。

对于每组测试数据：

  • 第一行包含两个正整数 n,mn, mn,m (1≤n≤5⋅105, 1≤m≤109)(1 \le n \le 5\cdot10^5,\ 1 \le m \le 10^{9})(1≤n≤5⋅105, 1≤m≤109)。
  • 第二行包含 nnn 个正整数 a1,…,ana_1, \dots, a_na1​,…,an​ (1≤ai≤109)(1 \le a_i \le 10^9)(1≤ai​≤109)。

保证所有测试数据中 nnn 的总和不超过 5⋅1055\cdot10^55⋅105。

输出格式

对于每组测试数据，输出一行，包含一个整数，表示在游戏结束后 Yuki 最多能拥有的士兵数量。

思路

先将所有堡垒按照 aia_iai​ 从小到大排序，显然优先占领代价更小的堡垒更优。

维护当前时间 timtimtim、士兵数 xxx 和堡垒数 yyy。

对于当前堡垒 aia_iai​，如果 x<aix<a_ix<ai​，则需要等待若干秒生产士兵。最少需要等待

d=⌈ai−xy⌉d=\left\lceil\frac{a_i-x}{y}\right\rceil d=⌈yai​−x​⌉

秒，随后更新

tim←tim+dtim\leftarrow tim+d tim←tim+d

x←x+d×yx\leftarrow x+d\times y x←x+d×y

如果此时 tim>mtim>mtim>m，说明已经没有时间占领这个堡垒，直接结束。

假设在第 timtimtim 秒结束时占领该堡垒，那么它在剩余时间内一共还能额外生产

m−timm-tim m−tim

个士兵，而占领它需要消耗 aia_iai​ 个士兵。

因此只有当

ai≤m−tima_i\le m-tim ai​≤m−tim

时，占领它才不会使最终士兵数变少。

又因为 aia_iai​ 已经从小到大排序，如果当前堡垒都不值得占领，那么后面的堡垒也一定不值得占领，可以直接退出。

占领后更新

x←x−aix\leftarrow x-a_i x←x−ai​

y←y+1y\leftarrow y+1 y←y+1

最后剩余的 m−timm-timm−tim 秒不再进行操作，直接生产士兵，因此答案为

x+(m−tim)×yx+(m-tim)\times y x+(m−tim)×y

整体复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

A

题目描述

Yuki 有一个长度为 nnn 的序列 aaa。

Yuki 定义一次操作为：

  • 选择一个 长度为偶数 的区间 [l,r][l,r][l,r]。对于每个满足 l≤i≤rl \le i \le rl≤i≤r 的正整数 iii：
    • 若 i−li-li−l 为奇数，则 aia_iai​ 的值减少 111，即 ai←ai−1a_i \gets a_i-1ai​←ai​−1。
    • 若 i−li-li−l 为偶数，则 aia_iai​ 的值增加 111，即 ai←ai+1a_i \gets a_i+1ai​←ai​+1。

现在，Yuki 想进行若干次操作，使得序列 aaa 中的所有数均相等。你需要帮助 Yuki 求出，使序列 aaa 中的所有数均相等的最小操作次数，或报告无解。

输入格式

本题包含多组测试数据。

第一行包含一个正整数 ttt (1≤t≤105)(1 \le t \le 10^5)(1≤t≤105)，表示测试数据组数。

对于每组测试数据：

  • 第一行包含一个正整数 nnn (1≤n≤106)(1 \le n \le 10^6)(1≤n≤106)。
  • 第二行包含 nnn 个整数 a1,…,ana_1,\dots,a_na1​,…,an​ (0≤ai≤1012)(0 \le a_i \le 10^{12})(0≤ai​≤1012)。

保证所有测试数据中 nnn 的总和不超过 10610^6106。

输出格式

对于每组测试数据，输出一行：

  • 若无解，则输出一个整数 −1-1−1。
  • 若有解，则输出一个整数，表示使序列 aaa 中的所有数均相等的最小操作次数。

思路

一次操作选择一个长度为偶数的区间，并对区间内元素依次执行 +1,−1,+1,−1,…+1,-1,+1,-1,\dots+1,−1,+1,−1,…。

显然一次操作不会改变整个数组的元素和，因此最终所有数如果能够相等，那么它们一定都等于平均值

$ x=\dfrac{\sum a_i}{n} $

所以如果 ∑ai\sum a_i∑ai​ 不能被 nnn 整除，则一定无解。

设前缀和为

$ S_i=\sum_{j=1}^{i}a_j $

最终前 iii 个数的和应该变为 ixixix，定义

$ d_i=ix-S_i $

表示第 iii 个前缀和还需要增加多少。

考虑一次对区间 [l,r][l,r][l,r] 的操作。由于区间内的变化为 +1,−1,+1,−1,…+1,-1,+1,-1,\dots+1,−1,+1,−1,…，它对前缀和的影响只会出现在

$ l,l+2,l+4,\dots,r-1 $

这些位置，并且这些位置的前缀和都会增加 111。

因此操作只能让前缀和增加，不能减少，所以必须满足

$ d_i\ge 0 $

若存在 di<0d_i<0di​<0，则无解。

同时可以发现，一次操作只会影响同一种奇偶性的下标，所以将奇数位置和偶数位置分别处理。

对于同一奇偶性的 ddd 序列，一次操作相当于选择其中一段连续区间全部减 111。将整个序列变为 000 的最少操作次数，就是所有“上升部分”的贡献之和。

因此对于位置 iii，其贡献为

$ \max(0,d_i-d_{i-2}) $

分别维护奇数位置和偶数位置上一个 ddd 的值，扫描一遍即可得到答案。

时间复杂度为 O(n)O(n)O(n)。

J

题目描述

Yuki 是 国际凸多边形锦标赛（International Convex Polygon Championship, ICPC）的裁判长。他为比赛提出了一道几何题。然而，由于他在几何方面经验不足，未能生成正确的凸多边形数据。

为了证明自己的几何能力，Yuki 再次开始玩起了木棍。他有 nnn 根木棍，第 iii 根木棍的长度为 aia_iai​。他打算从中选出至少 333 根木棍，使得这些木棍可以组成一个非退化凸多边形∗^\ast∗。

然而，由于 Yuki 并不了解几何方面的知识，他不知道应该如何选择木棍。作为 Yuki 的好朋友，你需要帮助他找到木棍的一个子集，使得：

  • 该子集中包含至少 333 根木棍，且包含的木棍数量尽可能多；
  • Yuki 从该子集中 任意 选出至少 333 根木棍，这些木棍都可以组成一个非退化凸多边形。

或报告不存在满足要求的子集。

∗^\ast∗：所有边长大于零、没有三点共线且所有内角严格小于 180∘180^\circ180∘ 的凸多边形被称作非退化凸多边形。

输入格式

本题包含多组测试数据。

第一行包含一个正整数 ttt (1≤t≤105)(1 \le t \le 10^5)(1≤t≤105)，表示测试数据组数。

对于每组测试数据：

  • 第一行包含一个正整数 nnn (3≤n≤5⋅105)(3 \le n \le 5\cdot10^5)(3≤n≤5⋅105)。
  • 第二行包含 nnn 个正整数 a1,…,ana_1, \dots, a_na1​,…,an​ (1≤ai≤109)(1 \le a_i \le 10^9)(1≤ai​≤109)。

保证所有测试数据中 nnn 的总和不超过 5⋅1055\cdot10^55⋅105。

输出格式

对于每组测试数据，输出一行：

  • 若不存在满足要求的子集，则输出一个整数 000。
  • 若存在满足要求的子集，则先输出一个整数 kkk，表示你找到的子集的大小，再输出 kkk 个整数 b1,…,bkb_1, \dots, b_kb1​,…,bk​，表示你找到的子集中的 kkk 根木棍的长度。

思路

先将所有木棍长度从小到大排序。

设我们选出的集合排序后为

b1≤b2≤⋯≤bkb_1\le b_2\le \cdots \le b_kb1​≤b2​≤⋯≤bk​

若这些木棍能够组成非退化凸多边形，需要满足最长边小于其余边之和。

而题目要求任意选出至少 333 根都合法，因此最危险的情况就是取最短的两根和最长的一根，也就是：

b1+b2>bkb_1+b_2>b_kb1​+b2​>bk​

只要这个条件成立，那么任意其它子集的最小两根之和都不会小于 b1+b2b_1+b_2b1​+b2​，最大边也不会大于 bkb_kbk​，所以同样合法。

因此问题转化为：

找到尽可能多的数，使得其中最小的两个数之和大于最大值。

排序后，可以证明一定存在一个最优答案是连续区间。

设当前区间左端点为 lll，右端点为 rrr，那么需要满足：

al+al+1>ara_l+a_{l+1}>a_ral​+al+1​>ar​

对于固定的 lll，不断向右移动 rrr，直到再加入下一个数后不满足条件。

随着 lll 增大，al+al+1a_l+a_{l+1}al​+al+1​ 单调不减，因此右指针 rrr 不需要回退，可以直接使用双指针维护最长合法区间。

排序复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，双指针扫描复杂度为 O(n)O(n)O(n)，总复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

B

题目描述

在一个平面直角坐标系上有一个机器人。初始时机器人位于 (0,0)(0,0)(0,0)，Yuki 想要通过一系列指令使机器人到达 (x,y)(x,y)(x,y)。

具体而言，一个指令串为仅包含 01\texttt{01}01 的字符串：

  • 0\texttt{0}0 表示向右移动一步，即令机器人的位置由 (a,b)(a,b)(a,b) 变为 (a+1,b)(a+1,b)(a+1,b)。
  • 1\texttt{1}1 表示向上移动一步，即令机器人的位置由 (a,b)(a,b)(a,b) 变为 (a,b+1)(a,b+1)(a,b+1)。

现在，Yuki 有一个仅包含 012\texttt{012}012 的长度为 nnn 的指令串 s=s1…sns=s_1\dots s_ns=s1​…sn​。Yuki 需要先将这个指令串的 2\texttt{2}2 都替换成 0\texttt{0}0 或 1\texttt{1}1，然后机器人会按照如下规则进行操作：

  • 对于每个非负整数 iii，在第 iii 秒时，若机器人不位于 (x,y)(x,y)(x,y)，则机器人会执行指令串的第 ((i mod n)+1)((i \bmod n)+1)((imodn)+1) 个指令。

Yuki 希望找到一种替换方式，使得在机器人能够到达 (x,y)(x,y)(x,y) 的基础上，指令串的字典序尽可能小。你需要帮助 Yuki 求出，字典序最小的满足条件的替换后的指令串，或报告不存在满足条件的指令串。

输入格式

本题包含多组测试数据。

第一行包含一个正整数 ttt (1≤t≤105)(1 \le t \le 10^5)(1≤t≤105)，表示测试数据组数。

对于每组测试数据：

  • 第一行包含三个整数 n,x,yn, x, yn,x,y (1≤n≤106, 0≤x,y≤1018)(1 \le n \le 10^6,\ 0 \le x, y \le 10^{18})(1≤n≤106, 0≤x,y≤1018)。
  • 第二行包含一个长度为 nnn 的字符串 sss (si∈{0,1,2})(s_i \in \{\texttt 0,\texttt 1,\texttt 2\})(si​∈{0,1,2})。

保证所有测试数据中 nnn 的总和不超过 10610^6106。

输出格式

对于每组测试数据，输出一行：

  • 若不存在满足条件的指令串，则输出一个整数 −1-1−1。
  • 若存在满足条件的指令串，则输出一个长度为 nnn 的字符串，表示字典序最小的满足条件的替换后的指令串。

思路

机器人从 (0,0)(0,0)(0,0) 出发，每执行一次指令，x+yx+yx+y 都会增加 111。

因此如果机器人最终到达目标点 (x,y)(x,y)(x,y)，那么它一定恰好执行

x+yx+yx+y

步。

设

m=x+ym=x+ym=x+y

那么问题就转化成：

在循环执行字符串的前 mmm 步中，恰好有 xxx 次执行的是 0。

因为 0 会让横坐标增加 111，而剩下的 m−x=ym-x=ym−x=y 次自然就是 1。

设

q=⌊mn⌋q=\lfloor\frac{m}{n}\rfloorq=⌊nm​⌋

r=m mod nr=m\bmod nr=mmodn

那么前 mmm 次执行相当于完整执行字符串 qqq 轮，再执行前 rrr 个字符。

所以：

  • 前 rrr 个位置会被执行 q+1q+1q+1 次；
  • 后 n−rn-rn−r 个位置会被执行 qqq 次。

也就是说，如果第 iii 个位置最后填成 0，它对横坐标的贡献为

wi=q+[i<r]w_i=q+[i<r]wi​=q+[i<r]

其中 [i<r][i<r][i<r] 表示条件成立时为 111，否则为 000。

先把字符串中所有固定的 0 的贡献减掉。

设剩下还需要贡献的横向步数为 needneedneed。

对于字符 2，可以分成两类：

  • 前 rrr 个位置中的 2，每个填成 0 可以贡献 q+1q+1q+1；
  • 后面位置中的 2，每个填成 0 可以贡献 qqq。

设这两类 2 的数量分别为 A,BA,BA,B。

那么我们需要判断是否存在整数 u,vu,vu,v 满足

u(q+1)+vq=needu(q+1)+vq=needu(q+1)+vq=need

并且

0≤u≤A0\le u\le A0≤u≤A

0≤v≤B0\le v\le B0≤v≤B

由

u(q+1)+vq=du(q+1)+vq=du(q+1)+vq=d

可以得到

v=d−u(q+1)qv=\frac{d-u(q+1)}qv=qd−u(q+1)​

首先需要满足 v≥0v\ge0v≥0，因此

u≤dq+1u\le\frac d{q+1}u≤q+1d​

所以右端点为

R=min⁡(A,⌊dq+1⌋)R=\min(A,\lfloor\frac d{q+1}\rfloor)R=min(A,⌊q+1d​⌋)

同时需要满足 v≤Bv\le Bv≤B，即

d−u(q+1)≤qBd-u(q+1)\le qBd−u(q+1)≤qB

整理得到

u≥d−qBq+1u\ge\frac{d-qB}{q+1}u≥q+1d−qB​

因此左端点为

L=max⁡(0,⌈d−qBq+1⌉)L=\max(0,\lceil\frac{d-qB}{q+1}\rceil)L=max(0,⌈q+1d−qB​⌉)

另外，vvv 必须是整数，所以需要

d−u(q+1)≡0(modq)d-u(q+1)\equiv0\pmod qd−u(q+1)≡0(modq)

因为

q+1≡1(modq)q+1\equiv1\pmod qq+1≡1(modq)

所以等价于

u≡d(modq)u\equiv d\pmod qu≡d(modq)

因此只要判断区间 [L,R][L,R][L,R] 中是否存在一个满足

u≡d(modq)u\equiv d\pmod qu≡d(modq)

的整数即可。

当 q=0q=0q=0 时需要单独处理。

此时有

m<nm<nm<n

也就是说机器人只会执行字符串的前 mmm 个字符一次，后面的字符完全不会被执行。

因此只有前 r=mr=mr=m 个位置中的 2 能产生贡献，每个贡献为 111。

只需要判断

0≤need≤A0\le need\le A0≤need≤A

即可。

最后考虑字典序最小。

因为

0 <<< 1

所以我们从左到右枚举每个 2，优先尝试把当前位置填成 0。

假设当前位置填成 0 后贡献为 www，那么新的需求变成

need−wneed-wneed−w

此时调用上面的可行性判断，检查剩余的 2 是否还能凑出 need−wneed-wneed−w。

如果可以，就令当前位置为 0；否则只能令当前位置为 1。

由于字典序优先比较最靠前的不同位置，所以只要当前位置能够填 0 并且后面仍然存在合法方案，就一定应该填 0。

因此从左到右这样贪心即可得到字典序最小的答案。

总复杂度为 O(n)O(n)O(n)。

题目描述

Yuki 发现一个回文括号串不可能是平衡括号串，因此她设计了另一种定义回文平衡括号串的方式。

Yuki 按照如下规则定义了 回文括号串：
