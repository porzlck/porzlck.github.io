Codeforces Round 748 (Div.3) F,G

F

题目描述

给定一个非负整数 xxx，其十进制表示包含 nnn 位数字。你需要将每一位数字涂成红色或黑色，使得由红色数字组成的数能被 AAA 整除，由黑色数字组成的数能被 BBB 整除。

每种颜色至少要涂一个数字。设红色数字的个数为 rrr，黑色数字的个数为 bbb。在所有可能的涂色方案中，你需要输出一个使 ∣r−b∣|r-b|∣r−b∣ 最小的方案。

注意，xxx 以及由每种颜色数字组成的数都可以包含前导零。


上图展示了 A=3A=3A=3，B=13B=13B=13 时，对 x=02165x=02165x=02165（n=5n=5n=5）的涂色示例。红色数字组成的数为 015015015，能被 333 整除，黑色数字组成的数为 262626，能被 131313 整除。注意红色和黑色数字数量之差的绝对值为 111，无法取得更小的值。

输入格式

第一行包含一个整数 ttt（1≤t≤101 \le t \le 101≤t≤10），表示测试用例的数量。接下来有 ttt 组测试用例。

每组测试用例包含两行。第一行包含三个整数 nnn、AAA、BBB（2≤n≤402 \le n \le 402≤n≤40，1≤A,B≤401 \le A, B \le 401≤A,B≤40）。第二行包含一个非负整数 xxx，恰好有 nnn 位数字，可能包含前导零。

输出格式

对于每个测试用例，输出一行：

  • 如果不存在满足条件的涂色方案，输出 −1-1−1；
  • 否则输出一个长度为 nnn 的字符串 sss，每个字符为 'R' 或 'B'。如果第 iii 位数字被涂成红色，则 sss 的第 iii 个字符为 'R'，否则为 'B'。

由红色数字组成的数应能被 AAA 整除，由黑色数字组成的数应能被 BBB 整除。∣r−b∣|r-b|∣r−b∣ 应尽量小，其中 rrr 为红色数字数量，bbb 为黑色数字数量。如果有多种方案，输出任意一种。

G

题目描述

给定一个由圆括号和方括号组成的序列。你可以通过以下操作改变该序列：

  1. 改变括号的方向，即将左括号变为右括号，右括号变为左括号，但不改变括号的类型：即可以将 '(' 变为 ')'，')' 变为 '('；可以将 '[' 变为 ']'，']' 变为 '['。该操作费用为 000 布尔。
  2. 将任意方括号变为相同方向的圆括号：即可以将 '[' 变为 '('，但不能将 '(' 变为 '['；同理，可以将 ']' 变为 ')'，但不能将 ')' 变为 ']'。该操作费用为 111 布尔。

上述操作可以以任意顺序、任意次数进行。

给定一个长度为 nnn 的字符串 sss，以及 qqq 个查询，每个查询为 "l r"，其中 1≤l<r≤n1 \le l < r \le n1≤l<r≤n。对于每个子串 s[l…r]s[l \dots r]s[l…r]，求将其变为合法括号序列所需支付的最小费用。保证子串 s[l…r]s[l \dots r]s[l…r] 的长度为偶数。

每个查询需要独立处理，即第 iii 个问题的答案所做的更改不会影响第 jjj 个问题（j>ij > ij>i）。换句话说，对于每个查询，子串 s[l…r]s[l \dots r]s[l…r] 都是从最初给定的字符串 sss 中截取的。

一个合法的括号序列需满足以下规则：

  • 空序列是合法括号序列；
  • 如果 "s" 是合法括号序列，则 "(s)" 和 "[s]" 也是合法括号序列；
  • 如果 "s" 和 "t" 都是合法括号序列，则 "st"（即连接后的序列）也是合法括号序列。

例如，序列 ""、"(()[])"、"[()()]()" 和 "(())()" 是合法括号序列，而 "("、"[(])" 和 ")))" 不是。

输入格式

第一行包含一个整数 ttt（1≤t≤1001 \le t \le 1001≤t≤100），表示测试用例的数量。接下来有 ttt 组测试用例。

对于每组测试用例，第一行包含一个非空字符串 sss，仅由圆括号 '('、')' 和方括号 '['、']' 组成。字符串长度不超过 10610^6106，且至少包含 222 个字符。

第二行包含一个整数 qqq（1≤q≤2×1051 \le q \le 2 \times 10^51≤q≤2×105），表示查询的数量。

接下来 qqq 行，每行包含两个整数 lll 和 rrr（1≤l<r≤n1 \le l < r \le n1≤l<r≤n，其中 nnn 是 sss 的长度）。保证子串 s[l…r]s[l \dots r]s[l…r] 的长度为偶数。

保证所有测试用例中所有字符串的总长度不超过 10610^6106。所有测试用例中所有 qqq 的总和不超过 2×1052 \times 10^52×105。

输出格式

对于每个测试用例的每个查询，输出一个整数 xxx（x≥0x \ge 0x≥0），表示将给定子串变为合法括号序列所需支付的最小费用。每个查询输出一行。

思路

由于改变括号方向的费用为 000，所以一个括号原本是左括号还是右括号其实不重要，真正影响答案的只有它是圆括号还是方括号。

对于任意一对匹配括号，设它们的位置为 i,ji,ji,j。因为它们内部一定包含偶数个字符，所以：

j−i−1j-i-1 j−i−1

为偶数，因此：

j−ij-i j−i

为奇数。

也就是说，一对匹配括号一定分别位于一个奇数位置和一个偶数位置。

因此在一个合法括号序列中，同一种括号类型在奇数位置和偶数位置出现的次数必须相等。

设当前查询区间内：

  • 奇数位置上的方括号数量为 xxx；
  • 偶数位置上的方括号数量为 yyy。

如果 x>yx>yx>y，那么至少有 x−yx-yx−y 个奇数位置上的方括号无法与偶数位置上的方括号匹配，只能花费 111 将它们变成圆括号。

同理，当 y>xy>xy>x 时，需要修改 y−xy-xy−x 个方括号。

所以答案就是：

∣x−y∣|x-y| ∣x−y∣

因此可以给每个位置赋值：

  • 如果当前位置是方括号，则根据下标奇偶性记为 111 或 −1-1−1；
  • 如果当前位置是圆括号，则记为 000。

然后维护前缀和 pre。
