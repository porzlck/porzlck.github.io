Codeforces Round 954 (Div.3) F,G2

F

题目描述

给定一个连通的无向图，其顶点用从 111 到 nnn 的整数编号。你的任务是最小化在这个图中存在路径的顶点对 (u,v)(u,v)(u,v) 的数量，其中 1≤u<v≤n1\le u\lt v\le n1≤u<v≤n。为了达到这个目标，你可以从图中移除恰好一条边。

现在请你找到可以移除一条边后，顶点对数量最小的值！

输入格式

每个测试包含多组输入数据。第一行包含一个整数 ttt（1≤t≤1041\le t\le 10^41≤t≤104），表示输入数据集的数量。然后是每组数据的描述：

每组数据的第一行包含两个整数 nnn 和 mmm（2≤n≤1052\le n\le 10^52≤n≤105，n−1≤m≤min⁡(105,n(n−1)2)n-1\le m\le\min(10^5,\frac{n(n-1)}{2})n−1≤m≤min(105,2n(n−1)​)，分别表示图中顶点的数量和边的数量。

接下来的m行，每行包含两个整数 uuu 和 vvv（1≤u,v≤n,u≠v1\le u,v\le n,u\ne v1≤u,v≤n,u​=v），表示在图中顶点 uuu 和 vvv 之间存在一条无向边。

保证给定的图是连通的，并且没有重边。

保证所有输入数据集中 nnn 的总和以及 mmm 的总和都不超过 2×1052\times10^52×105。

输出格式

对于每组输入数据，输出在移除一条边后，顶点对数量最小的值

思路

原图是连通图，所以一开始所有点对都互相可达，总数为：

n(n−1)2\frac{n(n-1)}{2} 2n(n−1)​

如果删掉的边不是割边，那么删边后图仍然连通，答案不会变。

所以只需要考虑删除 割边。

用 Tarjan 求桥。对于 DFS 树边 x -> y，如果：

那么 (x,y) 是一条桥。

同时在 DFS 中维护 siz[x]，表示以 x 为根的 DFS 子树大小。

如果 (x,y) 是桥，那么删除它后，y 的整棵子树会和其他点断开，因此两个连通块大小分别为：

siz[y] 和 n - siz[y]

这时有：

siz[y]×(n−siz[y])siz[y] \times (n-siz[y]) siz[y]×(n−siz[y])

对点变得不可达。

因此我们只需要在所有桥中最大化：

siz[y]×(n−siz[y])siz[y] \times (n-siz[y]) siz[y]×(n−siz[y])

最终答案为：

n(n−1)2−max⁡(siz[y]×(n−siz[y]))\frac{n(n-1)}{2} - \max(siz[y] \times (n-siz[y])) 2n(n−1)​−max(siz[y]×(n−siz[y]))

如果图中没有桥，那么最大值为 0，答案就是原来的：

n(n−1)2\frac{n(n-1)}{2} 2n(n−1)​

时间复杂度：

O(n+m)O(n+m) O(n+m)

G2

题目描述

这是该问题的困难版本。唯一的区别在于本版本中 n≤5⋅105n \leq 5 \cdot 10^5n≤5⋅105，且所有输入数据集合的 nnn 之和不超过 5⋅1055 \cdot 10^55⋅105。

给定一个长度为 nnn 的排列 ppp。计算有多少对下标 1≤i<j≤n1 \leq i < j \leq n1≤i<j≤n 满足 pi⋅pjp_i \cdot p_jpi​⋅pj​ 能被 i⋅ji \cdot ji⋅j 整除。

排列是一个长度为 nnn 的整数序列，其中每个整数 111 到 nnn 恰好出现一次。例如，[1][1][1]、[3,5,2,1,4][3,5,2,1,4][3,5,2,1,4]、[1,3,2][1,3,2][1,3,2] 是排列，而 [2,3,2][2,3,2][2,3,2]、[4,3,1][4,3,1][4,3,1]、[0][0][0] 不是排列。

输入格式

每组测试数据包含若干组输入数据。第一行包含一个整数 ttt（1≤t≤1041 \leq t \leq 10^41≤t≤104），表示输入数据的组数。接下来是每组数据的描述。

每组数据的第一行包含一个整数 nnn（1≤n≤5⋅1051 \leq n \leq 5 \cdot 10^51≤n≤5⋅105），表示排列 ppp 的长度。

每组数据的第二行包含 nnn 个互不相同的整数 p1,p2,…,pnp_1, p_2, \ldots, p_np1​,p2​,…,pn​（1≤pi≤n1 \leq p_i \leq n1≤pi​≤n），表示排列 ppp。

保证所有输入数据集合的 nnn 之和不超过 5⋅1055 \cdot 10^55⋅105。

输出格式

对于每组输入数据，输出满足条件的下标对 1≤i<j≤n1 \leq i < j \leq n1≤i<j≤n 的数量，使得 pi⋅pjp_i \cdot p_jpi​⋅pj​ 能被 i⋅ji \cdot ji⋅j 整除。

思路

对于每个位置 iii，令

g=gcd⁡(pi,i),u=pig,v=ig.g=\gcd(p_i,i),\qquad u=\frac{p_i}{g},\qquad v=\frac{i}{g}. g=gcd(pi​,i),u=gpi​​,v=gi​.

显然有

gcd⁡(u,v)=1.\gcd(u,v)=1. gcd(u,v)=1.

对于两个位置，设约分后分别为 (u,v)(u,v)(u,v) 和 (s,t)(s,t)(s,t)，原条件

ij∣pipjij\mid p_ip_j ij∣pi​pj​

等价于

vt∣us.vt\mid us. vt∣us.

由于

gcd⁡(u,v)=1,gcd⁡(s,t)=1,\gcd(u,v)=1,\qquad \gcd(s,t)=1, gcd(u,v)=1,gcd(s,t)=1,

所以进一步等价于

v∣s,t∣u.\boxed{v\mid s,\qquad t\mid u}. v∣s,t∣u​.

因此问题转化为：对于每个点 (u,v)(u,v)(u,v)，统计有多少个点 (s,t)(s,t)(s,t) 满足 v∣sv\mid sv∣s 且 t∣ut\mid ut∣u。

定义：

  • A[v]A[v]A[v]：所有第二维为 vvv 的点的第一维 uuu；
  • B[u]B[u]B[u]：所有第一维为 uuu 的点的第二维 vvv。

接下来固定 vvv。

首先枚举 vvv 的所有倍数

s=v,2v,3v,…s=v,2v,3v,\dots s=v,2v,3v,…

这样保证了 v∣sv\mid sv∣s。对于所有第一维为 sss 的点 (s,t)(s,t)(s,t)，令

cnt[t]++cnt[t]++ cnt[t]++

然后枚举所有第二维为 vvv 的当前点 (u,v)(u,v)(u,v)。还需要满足

t∣u.t\mid u. t∣u.

因此枚举 uuu 的所有约数 ttt，累加

ans+=cnt[t].ans+=cnt[t]. ans+=cnt[t].

这样就同时满足了
