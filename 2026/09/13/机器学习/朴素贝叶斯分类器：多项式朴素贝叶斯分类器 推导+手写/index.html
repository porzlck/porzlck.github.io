朴素贝叶斯分类器：多项式朴素贝叶斯分类器 推导+手写

1. 贝叶斯分类

贝叶斯公式：

P(C∣X)=P(X∣C)P(C)P(X)P(C\mid X)=\frac{P(X\mid C)P(C)}{P(X)} P(C∣X)=P(X)P(X∣C)P(C)​

分类时只关心哪个类别概率最大。

对于同一个样本 XXX，P(X)P(X)P(X) 对所有类别都相同，因此：

C^=arg⁡max⁡CP(X∣C)P(C)\hat C=\arg\max_C P(X\mid C)P(C) C^=argCmax​P(X∣C)P(C)

2. 朴素贝叶斯

假设：

X=(x1,x2,…,xn)X=(x_1,x_2,\dots,x_n) X=(x1​,x2​,…,xn​)

严格来说：

P(X∣C)=P(x1∣C)P(x2∣x1,C)P(x3∣x1,x2,C)⋯P(X\mid C) = P(x_1\mid C) P(x_2\mid x_1,C) P(x_3\mid x_1,x_2,C) \cdots P(X∣C)=P(x1​∣C)P(x2​∣x1​,C)P(x3​∣x1​,x2​,C)⋯

朴素贝叶斯假设：

给定类别 CCC 后，各个特征条件独立。

因此：

P(X∣C)≈∏iP(xi∣C)P(X\mid C) \approx \prod_i P(x_i\mid C) P(X∣C)≈i∏​P(xi​∣C)

最终：

C^=arg⁡max⁡CP(C)∏iP(xi∣C)\hat C = \arg\max_C P(C)\prod_iP(x_i\mid C) C^=argCmax​P(C)i∏​P(xi​∣C)

这里的“朴素”，就是指这个条件独立假设。

3. 多项式朴素贝叶斯

用于计数型特征。

例如词表：

[免费,中奖,会议][\text{免费},\text{中奖},\text{会议}] [免费,中奖,会议]

邮件：

免费 免费 中奖

表示成：

x=[2,1,0]x=[2,1,0] x=[2,1,0]

也就是三个词分别出现 2,1,02,1,02,1,0 次。

如果类别为 CCC：

P(x∣C)∝∏iP(wi∣C)xiP(x\mid C) \propto \prod_iP(w_i\mid C)^{x_i} P(x∣C)∝i∏​P(wi​∣C)xi​

所以：

C^=arg⁡max⁡CP(C)∏iP(wi∣C)xi\hat C = \arg\max_C P(C)\prod_iP(w_i\mid C)^{x_i} C^=argCmax​P(C)i∏​P(wi​∣C)xi​

xix_ixi​ 表示第 iii 个词出现的次数。

4. 参数怎么训练

假设类别 CCC 中有两个样本：

[2,1,0][2,1,0] [2,1,0]

[1,2,0][1,2,0] [1,2,0]

按列相加：

[3,3,0][3,3,0] [3,3,0]

表示在类别 CCC 中：

  • 第一个词出现 333 次
  • 第二个词出现 333 次
  • 第三个词出现 000 次

总词数为：

3+3+0=63+3+0=6 3+3+0=6

因此：

P(wi∣C)=NCi∑jNCjP(w_i\mid C) = \frac{N_{Ci}}{\sum_jN_{Cj}} P(wi​∣C)=∑j​NCj​NCi​​

其中 NCiN_{Ci}NCi​ 是第 iii 个词在类别 CCC 中的总出现次数。

5. 拉普拉斯平滑

如果某个词在训练集中一次都没有出现：

P(wi∣C)=0P(w_i\mid C)=0 P(wi​∣C)=0

整个乘积都会变成 000。

因此加入平滑：

P(wi∣C)=NCi+α∑jNCj+αdP(w_i\mid C) = \frac{N_{Ci}+\alpha} {\sum_jN_{Cj}+\alpha d} P(wi​∣C)=∑j​NCj​+αdNCi​+α​

其中：

  • α\alphaα 是平滑参数，通常取 111
  • ddd 是词表大小

例如：

[3,3,0][3,3,0] [3,3,0]

当 α=1\alpha=1α=1、d=3d=3d=3 时：

P(w1∣C)=49P(w_1\mid C)=\frac{4}{9} P(w1​∣C)=94​

P(w2∣C)=49P(w_2\mid C)=\frac{4}{9} P(w2​∣C)=94​

P(w3∣C)=19P(w_3\mid C)=\frac{1}{9} P(w3​∣C)=91​

6. 为什么要取 log

直接计算：

P(C)∏iP(wi∣C)xiP(C)\prod_iP(w_i\mid C)^{x_i} P(C)i∏​P(wi​∣C)xi​

会产生大量很小的数相乘，容易出现数值下溢。

因为：

log⁡(ab)=log⁡a+log⁡b\log(ab)=\log a+\log b log(ab)=loga+logb

所以改成：

log⁡P(C)+∑ixilog⁡P(wi∣C)\log P(C) + \sum_i x_i\log P(w_i\mid C) logP(C)+i∑​xi​logP(wi​∣C)

最终分类公式：

C^=arg⁡max⁡C(log⁡P(C)+∑ixilog⁡P(wi∣C))\hat C = \arg\max_C \left( \log P(C) + \sum_i x_i\log P(w_i\mid C) \right) C^=argCmax​(logP(C)+i∑​xi​logP(wi​∣C))

代码通常就是：

因为：

x@log⁡(feature_prob)=∑ixilog⁡P(wi∣C)x @ \log(\text{feature\_prob}) = \sum_i x_i\log P(w_i\mid C) x@log(feature_prob)=i∑​xi​logP(wi​∣C)
