朴素贝叶斯分类器：伯努利朴素贝叶斯分类器 推导+手写

1. 推导

前面已经学会了多项式朴素贝叶斯分类器，这个伯努利和其不同之处就在于多项式是统计出现次数，它是统计出没出现过，是二值的。

设：

X=(x1,x2,…,xn),xi∈{0,1}X=(x_1,x_2,\dots,x_n),\qquad x_i\in\{0,1\} X=(x1​,x2​,…,xn​),xi​∈{0,1}

贝叶斯分类：

P(C∣X)=P(X∣C)P(C)P(X)P(C\mid X) = \frac{P(X\mid C)P(C)}{P(X)} P(C∣X)=P(X)P(X∣C)P(C)​

分类时忽略公共分母：

C^=arg⁡max⁡CP(X∣C)P(C)\hat C = \arg\max_C P(X\mid C)P(C) C^=argCmax​P(X∣C)P(C)

给定类别 CCC 后，假设各特征条件独立：

P(X∣C)=∏i=1nP(xi∣C)P(X\mid C) = \prod_{i=1}^{n}P(x_i\mid C) P(X∣C)=i=1∏n​P(xi​∣C)

定义：

pi,C=P(xi=1∣C)p_{i,C}=P(x_i=1\mid C) pi,C​=P(xi​=1∣C)

则：

P(xi∣C)=pi,Cxi(1−pi,C)1−xiP(x_i\mid C) = p_{i,C}^{x_i}(1-p_{i,C})^{1-x_i} P(xi​∣C)=pi,Cxi​​(1−pi,C​)1−xi​

因此：

P(X∣C)=∏i=1npi,Cxi(1−pi,C)1−xiP(X\mid C) = \prod_{i=1}^{n} p_{i,C}^{x_i}(1-p_{i,C})^{1-x_i} P(X∣C)=i=1∏n​pi,Cxi​​(1−pi,C​)1−xi​

类别先验：

P(C)=NCNP(C)=\frac{N_C}{N} P(C)=NNC​​

拉普拉斯平滑：

pi,C=Ni,C+αNC+2αp_{i,C} = \frac{N_{i,C}+\alpha} {N_C+2\alpha} pi,C​=NC​+2αNi,C​+α​

实际计算通常取对数：

score(C)=log⁡P(C)+∑i=1n[xilog⁡pi,C+(1−xi)log⁡(1−pi,C)]\text{score}(C) = \log P(C) + \sum_{i=1}^{n} \left[ x_i\log p_{i,C} + (1-x_i)\log(1-p_{i,C}) \right] score(C)=logP(C)+i=1∑n​[xi​logpi,C​+(1−xi​)log(1−pi,C​)]

最终预测：

C^=arg⁡max⁡Cscore(C)\hat C = \arg\max_C \text{score}(C) C^=argCmax​score(C)
