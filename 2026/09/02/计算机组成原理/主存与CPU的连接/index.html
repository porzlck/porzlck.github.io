主存与CPU的连接

发表于2026-09-02|更新于2026-09-03|计算机基础
|浏览量:

CPU 想要访问主存，本质上需要解决三个问题：

  • 访问哪个存储单元；
  • 读写什么数据；
  • 当前到底是在进行什么操作。

因此，CPU 和主存之间通常通过三类信号进行连接：

  • 地址线；
  • 数据线；
  • 控制线。

但实际的主存通常不是由一片存储芯片直接构成，而是由多片芯片组合起来。

所以除了理解总线之外，还需要理解存储芯片如何进行扩展，以及 CPU 如何从多片芯片中选出当前要访问的那一片。

存储芯片的基本结构

一片存储芯片通常可以表示成：

c×bc \times b c×b

其中：

  • ccc 表示存储单元的数量；
  • bbb 表示每个存储单元能够保存多少位数据。

例如：

4K×8bit4K \times 8bit 4K×8bit

MREQ 是什么

MREQ 是：

Memory Request

也就是“存储器请求”。

它表示 CPU 当前确实正在发起一次存储器访问。

地址总线上并不是只有 CPU 访问内存时才存在电平。即使 CPU 当前没有真正访问主存，地址线上依然可能保持某个地址。

因此不能看到某个地址，就立即让对应的存储芯片开始工作。

因此存储芯片主要有两种扩展方式：

  • 位扩展；
  • 字扩展。

两者也可以同时使用。

位扩展解决的是：

全译码与部分译码

地址译码并不一定要使用所有高位地址。

根据参与译码的地址线数量不同，可以分为全译码和部分译码。

全译码

全译码会使用所有必要的高位地址进行判断。

因此，一个地址空间通常只对应唯一的一组存储单元。

地址划分比较清晰。

部分译码

部分译码只使用一部分高位地址。

这样可以简化译码电路，但没有参与译码的那些地址位发生变化时，芯片仍然可能被选中。

于是会出现：

多个不同地址访问同一个物理存储位置。

这种现象也称为地址重叠或地址镜像。
