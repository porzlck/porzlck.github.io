数列分块 9

发表于2026-09-05|更新于2026-09-04|算法
|浏览量:

题目描述

给出一个长为 nnn 的数列，以及 nnn 个操作，操作涉及询问区间的最小众数。

输入格式

第一行输入一个数字 nnn。

第二行输入 nnn 个数字，第 iii 个数字为 aia_iai​，以空格隔开。

接下来输入 nnn 行询问，每行输入两个数字 lll、rrr，以空格隔开。

表示查询位于 [l,r][l,r][l,r] 的数字的众数。

输出格式

对于每次询问，输出一行一个数字表示答案。

说明/提示

子任务 1（40 分）：1≤n≤100000,−231≤ai≤231−11 \leq n \leq 100000, -2^{31} \leq a_i \leq 2^{31}-11≤n≤100000,−231≤ai​≤231−1。

子任务 2（60 分）：1≤n≤300000,−231≤ai≤231−11 \leq n \leq 300000, -2^{31} \leq a_i \leq 2^{31}-11≤n≤300000,−231≤ai​≤231−1。

对于所有数据，1≤n≤3000001 \leq n \leq 3000001≤n≤300000，1≤l≤r≤n1 \leq l \leq r \leq n1≤l≤r≤n。

思路

将序列分块，块长取 B=nB=\sqrt nB=n​。

对于一次询问 [l,r][l,r][l,r]，可以拆成：

  • 左边散块
  • 中间若干完整块
  • 右边散块

预处理 mode[i][j]mode[i][j]mode[i][j]，表示第 iii 块到第 jjj 块之间的最小众数。

查询时，先取中间完整块的众数作为候选答案。

为什么只需要再枚举左右散块中的数？

如果一个数 xxx 没有出现在左右散块中，那么它在整个 [l,r][l,r][l,r] 中的出现次数，就等于它在中间完整块中的出现次数。而中间完整块的众数 yyy 满足

cnt(y)≥cnt(x)cnt(y)\ge cnt(x)cnt(y)≥cnt(x)

所以 xxx 不可能比 yyy 更优。

因此最终答案一定来自：

中间完整块的众数+左右散块中出现的数中间完整块的众数+左右散块中出现的数中间完整块的众数+左右散块中出现的数

对于左右散块中的每个数 xxx，用 occ[x] 保存它所有出现的位置，通过二分计算 xxx 在 [l,r][l,r][l,r] 中的出现次数。

左右散块一共只有 O(n)O(\sqrt n)O(n​) 个位置，因此单次查询复杂度为

O(nlog⁡n)O(\sqrt n\log n)O(n​logn)

预处理复杂度为

O(nn)O(n\sqrt n)O(nn​)
