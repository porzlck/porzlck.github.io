Codeforces Round 1122 (Div.3) G

发表于2026-09-27|更新于2026-09-27|算法
|浏览量:

题目描述

Vihaan has a rooted tree ∗ ^{\text{∗}} ∗ with n n n nodes. The tree is rooted at node 1 1 1 .

Each node i i i has an initial value ai a_i ai​ and a modulus bi b_i bi​ . Let xi x_i xi​ denote the current value of node i i i . Initially, xi=ai x_i=a_i xi​=ai​ .

Vihaan may perform the following operation any number of times:

  • Choose a node u u u . Let s s s be the sum of the current values of all direct children of u u u , then replace xu x_u xu​ with (xu+s) mod bu (x_u+s)\bmod b_u (xu​+s)modbu​ .

After performing any number of operations, Vihaan wants to maximize the sum of the values of all nodes.

Determine the maximum possible sum.

∗ ^{\text{∗}} ∗ A tree is an undirected connected graph in which there are no cycles.

输入格式

The first line contains an integer t t t ( 1≤t≤104 1 \le t \le 10^4 1≤t≤104 ) — the number of test cases.

The first line of each test case contains an integer n n n ( 1≤n≤2⋅105 1 \le n \le 2 \cdot 10^5 1≤n≤2⋅105 ) — the number of nodes in the tree.

The second line contains n n n integers a1,a2,…,an a_1,a_2,\ldots,a_n a1​,a2​,…,an​ ( 0≤ai<bi 0 \le a_i \lt b_i 0≤ai​<bi​ ) — the initial values of the nodes.

The third line contains n n n integers b1,b2,…,bn b_1,b_2,\ldots,b_n b1​,b2​,…,bn​ ( 1≤bi≤109 1 \le b_i \le 10^9 1≤bi​≤109 ) — the moduli of the nodes.

Each of the next n−1 n-1 n−1 lines contains two integers u u u and v v v ( 1≤u,v≤n 1 \le u,v \le n 1≤u,v≤n ) — an edge between nodes u u u and v v v .

It is guaranteed that the given edges form a tree.

It is guaranteed that the sum of n n n over all test cases does not exceed 2⋅105 2 \cdot 10^5 2⋅105 .

输出格式

For each test case, print one integer — the maximum possible sum of the values of all nodes after performing any number of operations.

思路

对于每个节点 uuu，定义 dud_udu​ 表示节点 uuu 的可达步长，即节点 uuu 的所有可达值满足

xu≡au(moddu).x_u\equiv a_u\pmod{d_u}. xu​≡au​(moddu​).

考虑节点 uuu 的所有儿子。设所有儿子的初始值之和为

Su=∑v∈son(u)av.S_u=\sum_{v\in son(u)}a_v. Su​=v∈son(u)∑​av​.

如果儿子 vvv 的可达步长为 dvd_vdv​，那么它的可达值可以写成

xv=av+kdv.x_v=a_v+k d_v. xv​=av​+kdv​.

因此父节点 uuu 每次操作时得到的儿子和，可以在 SuS_uSu​ 的基础上产生若干个 dvd_vdv​ 的变化。

对于节点 uuu，每次操作相当于

xu←xu+s(modbu),x_u\leftarrow x_u+s\pmod{b_u}, xu​←xu​+s(modbu​),

其中 sss 是某个可达的儿子和。

在模 bub_ubu​ 意义下，所有这些增量能够生成的状态由它们和 bub_ubu​ 的 gcd 决定，因此有

du=gcd⁡(bu,Su,{dv∣dv<bv}).d_u= \gcd\left( b_u, S_u, \{d_v\mid d_v<b_v\} \right). du​=gcd(bu​,Su​,{dv​∣dv​<bv​}).

这里必须满足 dv<bvd_v<b_vdv​<bv​ 才把 dvd_vdv​ 加入 gcd。

因为如果

dv=bv,d_v=b_v, dv​=bv​,

那么

xv≡av(modbv),x_v\equiv a_v\pmod{b_v}, xv​≡av​(modbv​),

而 0≤xv<bv0\le x_v<b_v0≤xv​<bv​，所以节点 vvv 实际上只能取 ava_vav​，无法产生任何变化。

因此转移为

du=gcd⁡(bu,∑v∈son(u)av,{dv∣dv<bv})d_u= \gcd\left( b_u, \sum_{v\in son(u)}a_v, \{d_v\mid d_v<b_v\} \right) du​=gcd​bu​,v∈son(u)∑​av​,{dv​∣dv​<bv​}​

对于叶子节点，没有儿子，因此

du=gcd⁡(bu,0)=bu,d_u=\gcd(b_u,0)=b_u, du​=gcd(bu​,0)=bu​,

即叶子无法改变。

得到 dud_udu​ 后，节点 uuu 的可达值为

au, au+du, au+2du,…a_u,\ a_u+d_u,\ a_u+2d_u,\dots au​, au​+du​, au​+2du​,…

所以小于 bub_ubu​ 的最大可达值为

mxu=au+⌊bu−1−audu⌋du.mx_u= a_u+ \left\lfloor \frac{b_u-1-a_u}{d_u} \right\rfloor d_u. mxu​=au​+⌊du​bu​−1−au​​⌋du​.

操作某个节点只会修改该节点本身，因此父节点达到最大值后，可以不再操作父节点，再继续调整它的子树，所以所有节点最终都可以同时达到各自的最大可达值。

最终答案为

Ans=∑u=1nmxuAns=\sum_{u=1}^{n}mx_u Ans=u=1∑n​mxu​

树形 DP 从叶子向根计算 dud_udu​ 即可，时间复杂度为 O(n)O(n)O(n)。
