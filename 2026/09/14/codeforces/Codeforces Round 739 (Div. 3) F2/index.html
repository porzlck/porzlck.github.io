Codeforces Round 739 (Div.3) F2 15行核心代码解决2100分的题目？？？

发表于2026-09-14|更新于2026-09-14|算法
|浏览量:

题目描述

这是问题 F1 的复杂版本。它们之间的区别在于约束条件（F1：k≤2k \le 2k≤2，F2：k≤10k \le 10k≤10）。

给定一个整数 nnn。请你找出最小的整数 xxx，使得 x≥nx \ge nx≥n 且 xxx 是 kkk-美丽数。

如果一个数的十进制表示（不含前导零）中，不超过 kkk 种不同的数字，则称其为 kkk-美丽数。例如，当 k=2k = 2k=2 时，343444334344433434443、555505555055550、777777777 和 212121 是 kkk-美丽数，而 120120120、445435445435445435 和 998244353998244353998244353 不是。

输入格式

第一行包含一个整数 ttt（1≤t≤1041 \le t \le 10^41≤t≤104），表示测试用例的数量。接下来有 ttt 个测试用例。

每个测试用例包含一行，包含两个整数 nnn 和 kkk（1≤n≤1091 \le n \le 10^91≤n≤109，1≤k≤101 \le k \le 101≤k≤10）。

输出格式

对于每个测试用例，输出一行，表示最小的 kkk-美丽整数 xxx，满足 x≥nx \ge nx≥n。

思路

用一个二进制数记录当前数字中出现过哪些数字。

对于数字 xxx，若某一位为 ddd，则执行

mask∣=1<<dmask \mathrel{|}= 1<<d mask∣=1<<d

最后

popcount⁡(mask)\operatorname{popcount}(mask) popcount(mask)

就是 xxx 中不同数字的个数。

如果当前 nnn 已经满足不同数字数量 ≤k\le k≤k，那么答案显然就是 nnn。

否则，从右向左不断删除数字，也就是不断执行

c←⌊c10⌋c\leftarrow \left\lfloor\frac c{10}\right\rfloor c←⌊10c​⌋

直到剩下的前缀第一次满足不同数字数量 ≤k\le k≤k。

设此时被删除部分对应的数位权值为 rrr，那么原数中从这一位开始的前缀已经出现了超过 kkk 种数字。

因此，所有具有这个前缀的数都不可能成为答案，可以直接跳过整个区间。

将该前缀加一，并把后面的数字全部变成 000：

n=(⌊nr⌋+1)rn= \left( \left\lfloor\frac nr\right\rfloor+1 \right)r n=(⌊rn​⌋+1)r

然后继续判断新的 nnn 是否满足条件。

例如

n=177890,k=2n=177890,\quad k=2 n=177890,k=2

前缀 177177177 只有 222 种数字，而 177817781778 已经有 333 种数字，因此所有形如

1778xx1778xx 1778xx

的数字都不可能合法，可以直接跳到

177900177900 177900

继续处理。

不断进行这样的“进位 + 后缀清零”，最终得到的第一个满足条件的数字，就是最小的 kkk-beautiful 数。

正确性

如果某个前缀已经包含超过 kkk 种不同数字，那么任何包含该前缀的数字都一定不合法。

因此可以直接跳过整个具有该前缀的区间，不会遗漏更小的合法答案。

复杂度

数字最多只有约 101010 位，每次操作都会跳过一段不可能的区间，因此实际循环次数很少，复杂度可以认为是

O(log⁡2n)O(\log^2 n) O(log2n)

对于题目的数据范围完全足够。
