SVM（二）KKT 条件与支持向量

发表于2026-09-12|更新于2026-09-12|机器学习
|浏览量:

上一篇已经得到 Hard-Margin SVM 的原始问题：

min⁡w,b12wTw s.t.yi(wTxi+b)≥1,i=1,…,N\begin{aligned} \min_{w,b}\quad &\frac12 w^T w\ \text{s.t.}\quad &y_i(w^Tx_i+b)\geq1, \quad i=1,\dots,N \end{aligned} w,bmin​​21​wTw s.t.​yi​(wTxi​+b)≥1,i=1,…,N​

以及对应的对偶问题：

max⁡λ∑i=1Nλi−12∑i=1N∑j=1NλiλjyiyjxiTxj s.t.λi≥0 ∑i=1Nλiyi=0\begin{aligned} \max_{\lambda}\quad &\sum_{i=1}^{N}\lambda_i -\frac12 \sum_{i=1}^{N}\sum_{j=1}^{N} \lambda_i\lambda_jy_iy_jx_i^Tx_j\ \text{s.t.}\quad &\lambda_i\geq0\ &\sum_{i=1}^{N}\lambda_i y_i=0 \end{aligned} λmax​​i=1∑N​λi​−21​i=1∑N​j=1∑N​λi​λj​yi​yj​xiT​xj​ s.t.​λi​≥0 ​i=1∑N​λi​yi​=0​

同时有：

w=∑i=1Nλiyixiw=\sum_{i=1}^{N}\lambda_i y_i x_i w=i=1∑N​λi​yi​xi​

接下来要解决的问题是：得到 λi\lambda_iλi​ 之后，哪些样本真正决定分类面，以及如何恢复 www 和 bbb。这就需要 KKT 条件。

对于一般约束优化问题：

min⁡xf(x)\min_x f(x) xmin​f(x)

满足：

gi(x)≤0g_i(x)\leq0 gi​(x)≤0

拉格朗日函数为：

f(x)+∑iλigi(x)f(x)+\sum_i\lambda_i g_i(x) f(x)+i∑​λi​gi​(x)

其中：

λi≥0\lambda_i\geq0 λi​≥0

在满足相应条件的凸优化问题中，最优解需要满足 KKT 条件：

∇xL(x,λ)=0\nabla_xL(x,\lambda)=0 ∇x​L(x,λ)=0

gi(x)≤0g_i(x)\leq0 gi​(x)≤0

λi≥0\lambda_i\geq0 λi​≥0

以及最关键的互补松弛条件：

λigi(x)=0\lambda_i g_i(x)=0 λi​gi​(x)=0

这条式子的含义很直接。

如果某个约束在最优解处没有取等号，即：

gi(x)<0g_i(x)<0 gi​(x)<0

那么因为：

λigi(x)=0\lambda_i g_i(x)=0 λi​gi​(x)=0

只能有：

λi=0\lambda_i=0 λi​=0

如果：

λi>0\lambda_i>0 λi​>0

那么一定有：

gi(x)=0g_i(x)=0 gi​(x)=0

也就是说，只有真正贴在约束边界上的约束，才可能对应非零的拉格朗日乘子。

回到 Hard-Margin SVM，它的约束是：

yi(wTxi+b)≥1y_i(w^Tx_i+b)\geq1 yi​(wTxi​+b)≥1

写成标准形式：

1−yi(wTxi+b)≤01-y_i(w^Tx_i+b)\leq0 1−yi​(wTxi​+b)≤0

因此：

gi(w,b)=1−yi(wTxi+b)g_i(w,b)=1-y_i(w^Tx_i+b) gi​(w,b)=1−yi​(wTxi​+b)

SVM 的 KKT 条件为：

w−∑i=1Nλiyixi=0w-\sum_{i=1}^{N}\lambda_i y_i x_i=0 w−i=1∑N​λi​yi​xi​=0

即：

w=∑i=1Nλiyixi\boxed{ w=\sum_{i=1}^{N}\lambda_i y_i x_i } w=i=1∑N​λi​yi​xi​​

以及：

∑i=1Nλiyi=0\boxed{ \sum_{i=1}^{N}\lambda_i y_i=0 } i=1∑N​λi​yi​=0​

原问题约束：

yi(wTxi+b)≥1\boxed{ y_i(w^Tx_i+b)\geq1 } yi​(wTxi​+b)≥1​

对偶变量约束：

λi≥0\boxed{ \lambda_i\geq0 } λi​≥0​

互补松弛条件：

λi[1−yi(wTxi+b)]=0\boxed{ \lambda_i\left[1-y_i(w^Tx_i+b)\right]=0 } λi​[1−yi​(wTxi​+b)]=0​

这条式子把训练样本分成了两类。

如果：

yi(wTxi+b)>1y_i(w^Tx_i+b)>1 yi​(wTxi​+b)>1

那么：

1−yi(wTxi+b)≠01-y_i(w^Tx_i+b)\neq0 1−yi​(wTxi​+b)=0

所以必须有：

λi=0\boxed{ \lambda_i=0 } λi​=0​

这种样本位于 margin 外部，不直接决定最终的分类面。

如果：

λi>0\lambda_i>0 λi​>0

那么必须有：

1−yi(wTxi+b)=01-y_i(w^Tx_i+b)=0 1−yi​(wTxi​+b)=0

即：

yi(wTxi+b)=1\boxed{ y_i(w^Tx_i+b)=1 } yi​(wTxi​+b)=1​

这些样本正好落在 margin 边界上，也就是支持向量。

对于正类支持向量 yi=+1y_i=+1yi​=+1：

wTxi+b=1w^Tx_i+b=1 wTxi​+b=1

对于负类支持向量 yi=−1y_i=-1yi​=−1：

wTxi+b=−1w^Tx_i+b=-1 wTxi​+b=−1

因此两条 margin 边界分别是：

wTx+b=1w^Tx+b=1 wTx+b=1

和：

wTx+b=−1w^Tx+b=-1 wTx+b=−1

分类超平面则是：

wTx+b=0w^Tx+b=0 wTx+b=0

由于：

w=∑i=1Nλiyixiw=\sum_{i=1}^{N}\lambda_i y_i x_i w=i=1∑N​λi​yi​xi​

而非支持向量满足：

λi=0\lambda_i=0 λi​=0

所以实际上：

w=∑i∈SVλiyixi\boxed{ w=\sum_{i\in SV}\lambda_i y_i x_i } w=i∈SV∑​λi​yi​xi​​

也就是说，最终的分类超平面只由支持向量决定。

求解对偶问题得到 λ∗\lambda^*λ∗ 后，可以先计算：

w∗=∑i=1Nλi∗yixiw^*=\sum_{i=1}^{N}\lambda_i^*y_ix_i w∗=i=1∑N​λi∗​yi​xi​

然后任选一个满足：

λk∗>0\lambda_k^*>0 λk∗​>0

的支持向量。根据 KKT：

yk(wTxk+b)=1y_k(w^{T}x_k+b)=1 yk​(wTxk​+b)=1

由于 yk∈−1,+1y_k\in{-1,+1}yk​∈−1,+1，所以：

wTxk+b=ykw^{T}x_k+b=y_k wTxk​+b=yk​

因此：

b∗=yk−w∗Txkb^*=y_k-w^{*T}x_k b∗=yk​−w∗Txk​

最终分类器为：

f(x)=sign⁡(wTx+b)f(x)=\operatorname{sign}(w^{T}x+b) f(x)=sign(wTx+b)

再代入：

w∗=∑iλi∗yixiw^*=\sum_i\lambda_i^*y_ix_i w∗=i∑​λi∗​yi​xi​

得到：

f(x)=sign⁡(∑i∈SVλi∗yixiTx+b∗)f(x) = \operatorname{sign} \left( \sum_{i\in SV} \lambda_i^* y_i x_i^T x + b^* \right) f(x)=sign(i∈SV∑​λi∗​yi​xiT​x+b∗)

所以 KKT 在 SVM 中最重要的作用，可以概括为：

λi>0⇒yi(wTxi+b)=1\boxed{ \lambda_i>0 \Rightarrow y_i(w^Tx_i+b)=1 } λi​>0⇒yi​(wTxi​+b)=1​

即非零的 λi\lambda_iλi​ 对应支持向量，而非支持向量的 λi=0\lambda_i=0λi​=0。最终 www 和分类函数都只依赖这些支持向量。
