3.3 对数几率回归

对于二分类问题，类别只有：

Y∈{0,1}Y\in\{0,1\} Y∈{0,1}

设：

p=P(Y=1∣x)p=P(Y=1|x) p=P(Y=1∣x)

表示给定样本 xxx 时，属于类别 111 的概率。

因为只有两个类别：

P(Y=0∣x)=1−pP(Y=0|x)=1-p P(Y=0∣x)=1−p

几率与对数几率

类别 111 相对于类别 000 的几率（odds）为：

p1−p\frac{p}{1-p} 1−pp​

对几率取对数：

ln⁡p1−p\ln\frac{p}{1-p} ln1−pp​

称为对数几率（log odds）。

对数几率回归的核心假设是：

ln⁡p1−p=wTx+b\ln\frac{p}{1-p}=w^Tx+b ln1−pp​=wTx+b

也就是说：

概率 ppp 本身不是线性的，而是它的对数几率与输入 xxx 呈线性关系。

令：

z=wTx+bz=w^Tx+b z=wTx+b

则：

ln⁡p1−p=z\ln\frac{p}{1-p}=z ln1−pp​=z

两边取指数：

p1−p=ez\frac{p}{1-p}=e^z 1−pp​=ez

整理：

p=ez(1−p)p=e^z(1-p) p=ez(1−p)

p+ezp=ezp+e^zp=e^z p+ezp=ez

p(1+ez)=ezp(1+e^z)=e^z p(1+ez)=ez

因此：

p=ez1+ez=11+e−zp= \frac{e^z}{1+e^z} = \frac{1}{1+e^{-z}} p=1+ezez​=1+e−z1​

于是得到：

P(Y=1∣x)=11+e−(wTx+b)P(Y=1|x) = \frac{1}{1+e^{-(w^Tx+b)}} P(Y=1∣x)=1+e−(wTx+b)1​

这就是 Sigmoid 函数。

同时：

P(Y=0∣x)=1−P(Y=1∣x)P(Y=0|x) = 1-P(Y=1|x) P(Y=0∣x)=1−P(Y=1∣x)

因此：

P(Y=0∣x)=11+ewTx+bP(Y=0|x) = \frac{1}{1+e^{w^Tx+b}} P(Y=0∣x)=1+ewTx+b1​

如何分类

模型先计算：

z=wTx+bz=w^Tx+b z=wTx+b

再通过 Sigmoid 得到：

p=P(Y=1∣x)p=P(Y=1|x) p=P(Y=1∣x)

例如：

p=0.8p=0.8 p=0.8

表示模型估计该样本属于类别 111 的概率为 80%80\%80%。

通常使用 0.50.50.5 作为分类阈值：

p≥0.5⇒Y^=1p\ge0.5 \Rightarrow \hat Y=1 p≥0.5⇒Y^=1

p<0.5⇒Y^=0p<0.5 \Rightarrow \hat Y=0 p<0.5⇒Y^=0

由于：

σ(0)=0.5\sigma(0)=0.5 σ(0)=0.5

因此也可以直接根据：

wTx+bw^Tx+b wTx+b

判断：

wTx+b≥0⇒Y^=1w^Tx+b\ge0 \Rightarrow \hat Y=1 wTx+b≥0⇒Y^=1

wTx+b<0⇒Y^=0w^Tx+b<0 \Rightarrow \hat Y=0 wTx+b<0⇒Y^=0

最大化似然

将 www 和 bbb 合并：

β=[wb]\beta= \begin{bmatrix} w\\ b \end{bmatrix} β=[wb​]

将样本扩展为：

x^=[x1]\hat x= \begin{bmatrix} x\\ 1 \end{bmatrix} x^=[x1​]

于是：

βTx^=wTx+b\beta^T\hat x=w^Tx+b βTx^=wTx+b

对于训练集：

D={(xi,yi)}i=1mD=\{(x_i,y_i)\}_{i=1}^{m} D={(xi​,yi​)}i=1m​

其中：

yi∈{0,1}y_i\in\{0,1\} yi​∈{0,1}

希望找到一组参数 β\betaβ，使训练集中真实类别出现的概率尽可能大。

因此使用最大似然估计：

ℓ(β)=∏i=1mP(Y=yi∣xi;β)\ell(\beta) = \prod_{i=1}^{m} P(Y=y_i|x_i;\beta) ℓ(β)=i=1∏m​P(Y=yi​∣xi​;β)

对于单个样本，可以统一写成：

P(Y=yi∣xi)=piyi(1−pi)1−yiP(Y=y_i|x_i) = p_i^{y_i}(1-p_i)^{1-y_i} P(Y=yi​∣xi​)=piyi​​(1−pi​)1−yi​

其中：

pi=P(Y=1∣xi)p_i=P(Y=1|x_i) pi​=P(Y=1∣xi​)

所以整体似然为：

ℓ(β)=∏i=1mpiyi(1−pi)1−yi\ell(\beta) = \prod_{i=1}^{m} p_i^{y_i}(1-p_i)^{1-y_i} ℓ(β)=i=1∏m​piyi​​(1−pi​)1−yi​

最大化似然，等价于最小化负对数似然：

L(β)=−∑i=1m[yiln⁡pi+(1−yi)ln⁡(1−pi)]L(\beta) = -\sum_{i=1}^{m} \left[ y_i\ln p_i + (1-y_i)\ln(1-p_i) \right] L(β)=−i=1∑m​[yi​lnpi​+(1−yi​)ln(1−pi​)]

这就是二分类中的交叉熵损失。

将：

pi=11+e−βTx^ip_i= \frac{1}{1+e^{-\beta^T\hat x_i}} pi​=1+e−βTx^i​1​

代入，可以得到：

L(β)=∑i=1m[−yiβTx^i+ln⁡(1+eβTx^i)]L(\beta) = \sum_{i=1}^{m} \left[ -y_i\beta^T\hat x_i + \ln(1+e^{\beta^T\hat x_i}) \right] L(β)=i=1∑m​[−yi​βTx^i​+ln(1+eβTx^i​)]

其梯度为：

∇βL=∑i=1mx^i(pi−yi)\nabla_\beta L = \sum_{i=1}^{m} \hat x_i(p_i-y_i) ∇β​L=i=1∑m​x^i​(pi​−yi​)

因此可以通过梯度下降不断更新参数：

β←β−α∇βL\beta \leftarrow \beta-\alpha\nabla_\beta L β←β−α∇β​L

3.4 线性判别分析 LDA

LDA 的基本思想：

将样本投影到一条直线上，使同类样本尽可能接近，不同类别的中心尽可能远。

设二分类数据的均值为：

μ0,μ1\mu_0,\qquad\mu_1 μ0​,μ1​

投影方向为：

ww w

投影后的类别中心：

wTμ0,wTμ1w^T\mu_0, \qquad w^T\mu_1 wTμ0​,wTμ1​

类内散度矩阵

定义：

Sw=∑x∈X0(x−μ0)(x−μ0)T+∑x∈X1(x−μ1)(x−μ1)TS_w = \sum_{x\in X_0} (x-\mu_0)(x-\mu_0)^T + \sum_{x\in X_1} (x-\mu_1)(x-\mu_1)^T Sw​=x∈X0​∑​(x−μ0​)(x−μ0​)T+x∈X1​∑​(x−μ1​)(x−μ1​)T

SwS_wSw​ 描述同一类别内部样本的离散程度。

希望：

wTSwww^TS_ww wTSw​w

尽可能小。

类间散度矩阵

定义：

Sb=(μ0−μ1)(μ0−μ1)TS_b = (\mu_0-\mu_1) (\mu_0-\mu_1)^T Sb​=(μ0​−μ1​)(μ0​−μ1​)T

投影后两个类别中心的距离为：

wTSbww^TS_bw wTSb​w

希望它尽可能大。

LDA 优化目标

因此：

J(w)=wTSbwwTSwwJ(w) = \frac{w^TS_bw} {w^TS_ww} J(w)=wTSw​wwTSb​w​

目标：

max⁡wwTSbwwTSww\max_w \frac{w^TS_bw} {w^TS_ww} wmax​wTSw​wwTSb​w​

由于 www 的长度不影响结果，可以令：

wTSww=1w^TS_ww=1 wTSw​w=1

得到约束优化：

max⁡wwTSbw\max_w w^TS_bw wmax​wTSb​w

s.t. wTSww=1\text{s.t. } w^TS_ww=1 s.t. wTSw​w=1

由拉格朗日乘子法：

Sbw=λSwwS_bw = \lambda S_ww Sb​w=λSw​w

又因为：

Sbw=(μ0−μ1)(μ0−μ1)TwS_bw = (\mu_0-\mu_1) (\mu_0-\mu_1)^Tw Sb​w=(μ0​−μ1​)(μ0​−μ1​)Tw

其方向与：

μ0−μ1\mu_0-\mu_1 μ0​−μ1​

相同，因此最终得到：

w=Sw−1(μ0−μ1)w = S_w^{-1}(\mu_0-\mu_1) w=Sw−1​(μ0​−μ1​)

比例常数不影响投影方向。

多分类 LDA

对于 NNN 个类别，定义类内散度矩阵：

Sw=∑i=1N∑x∈Xi(x−μi)(x−μi)TS_w = \sum_{i=1}^{N} \sum_{x\in X_i} (x-\mu_i)(x-\mu_i)^T Sw​=i=1∑N​x∈Xi​∑​(x−μi​)(x−μi​)T

全局均值：

μ=1m∑i=1mxi\mu = \frac{1}{m} \sum_{i=1}^{m}x_i μ=m1​i=1∑m​xi​

类间散度矩阵：

Sb=∑i=1Nmi(μi−μ)(μi−μ)TS_b = \sum_{i=1}^{N} m_i (\mu_i-\mu) (\mu_i-\mu)^T Sb​=i=1∑N​mi​(μi​−μ)(μi​−μ)T

多分类 LDA 的目标为：

max⁡Wtr⁡(WTSbW)tr⁡(WTSwW)\max_W \frac{ \operatorname{tr}(W^TS_bW) }{ \operatorname{tr}(W^TS_wW) } Wmax​tr(WTSw​W)tr(WTSb​W)​

最终转化为广义特征值问题：

Sbw=λSwwS_bw = \lambda S_ww Sb​w=λSw​w

即求：

Sw−1SbS_w^{-1}S_b Sw−1​Sb​

最大的若干个特征值对应的特征向量。

对于 NNN 个类别，LDA 最多可以降到：

N−1N-1 N−1

维。
