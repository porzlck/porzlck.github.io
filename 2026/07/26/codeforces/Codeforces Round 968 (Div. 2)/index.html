CF2003D2 Turtle and a MEX Problem (Hard Version)

题目描述

两个版本的问题是不同的。在这个版本的问题中，你不能选择同一个整数两次或更多次。只有当两个版本都解决时，才能进行 hack。

有一天，乌龟正在玩 nnn 个序列。设第 iii 个序列的长度为 lil_ili​，则第 iii 个序列为 ai,1,ai,2,…,ai,lia_{i, 1}, a_{i, 2}, \ldots, a_{i, l_i}ai,1​,ai,2​,…,ai,li​​。

当乌龟在玩耍时，小猪给了他一个问题来解决。问题的陈述如下：

  • 最初有一个非负整数 xxx。乌龟可以对这个整数执行任意次数（可能为零）的操作。
  • 在每次操作中，乌龟可以选择一个之前未被选择过的整数 iii（满足 1≤i≤n1 \le i \le n1≤i≤n），并将 xxx 设为 mex†(x,ai,1,ai,2,…,ai,li)\text{mex}^{\dagger}(x, a_{i, 1}, a_{i, 2}, \ldots, a_{i, l_i})mex†(x,ai,1​,ai,2​,…,ai,li​​)。
  • 乌龟被要求找到答案，即在执行任意次数操作后 xxx 的最大值。

乌龟轻松解决了上述问题。他定义 f(k)f(k)f(k) 为初始值 xxx 为 kkk 时上述问题的答案。

然后小猪给了乌龟一个非负整数 mmm，并要求乌龟找出 ∑i=0mf(i)\sum\limits_{i = 0}^m f(i)i=0∑m​f(i) 的值（即 f(0)+f(1)+…+f(m)f(0) + f(1) + \ldots + f(m)f(0)+f(1)+…+f(m) 的值）。不幸的是，他无法解决这个问题。请帮助他！

mex(c1,c2,…,ck)\text{mex}(c_1, c_2, \ldots, c_k)mex(c1​,c2​,…,ck​) 定义为不在序列 ccc 中出现的最小非负整数 xxx。例如，mex(2,2,0,3)\text{mex}(2, 2, 0, 3)mex(2,2,0,3) 是 111，mex(1,2)\text{mex}(1, 2)mex(1,2) 是 000。

输入格式

每个测试包含多个测试用例。第一行包含测试用例的数量 ttt（1≤t≤1041 \le t \le 10^41≤t≤104）。接下来是测试用例的描述。

每个测试用例的第一行包含两个整数 n,mn, mn,m（1≤n≤2⋅105,0≤m≤1091 \le n \le 2 \cdot 10^5, 0 \le m \le 10^91≤n≤2⋅105,0≤m≤109）。

接下来的 nnn 行每行包含若干个整数。第一个整数 lil_ili​（1≤li≤2⋅1051 \le l_i \le 2 \cdot 10^51≤li​≤2⋅105）表示第 iii 个序列的长度，后面跟着 lil_ili​ 个整数 ai,1,ai,2,…,ai,lia_{i, 1}, a_{i, 2}, \ldots, a_{i, l_i}ai,1​,ai,2​,…,ai,li​​（0≤ai,j≤1090 \le a_{i, j} \le 10^90≤ai,j​≤109）表示第 iii 个序列的元素。

保证所有测试用例中的 nnn 之和不超过 2⋅1052 \cdot 10^52⋅105，并且所有测试用例中的 ∑li\sum l_i∑li​ 之和不超过 2⋅1052 \cdot 10^52⋅105。

输出格式

对于每个测试用例，输出一个整数 —— ∑i=0mf(i)\sum\limits_{i = 0}^m f(i)i=0∑m​f(i) 的值。

思路

对于每个序列，只需要求出它的前两个缺失非负整数。

设它们分别为：

u=mex⁡(ai)u=\operatorname{mex}(a_i)u=mex(ai​)

v=mex⁡(ai∪u)v=\operatorname{mex}(a_i\cup{u})v=mex(ai​∪u)

显然有 u<vu<vu<v。

对于当前值 xxx，使用这个序列后：

  • 如果 x=ux=ux=u，那么 uuu 被补上，结果变为 vvv；
  • 如果 x≠ux\ne ux​=u，那么 uuu 仍然是最小缺失值，结果变为 uuu。

因此，每个序列可以抽象成一条有向边：

u→vu\rightarrow vu→v

由于所有边都满足 u<vu<vu<v，所以整张图一定是 DAG。

定义：

dp[u]dp[u]dp[u]

表示当前值已经是 uuu 时，继续选择未使用的序列，最终最多能到达的值。

转移为：

dp[u]=max⁡(u,max⁡u→vdp[v])dp[u]=\max\left(u,\max_{u\rightarrow v}dp[v]\right)dp[u]=max(u,maxu→v​dp[v])

因为边总是从小点指向大点，所以可以从大到小计算 dpdpdp。

接下来定义 basebasebase，表示无论初始值是多少，都一定能够达到的最大值。

对于任意一条边 u→vu\rightarrow vu→v，如果当前值不等于 uuu，使用对应序列后就会变成 uuu；如果当前值本来就是 uuu，则不需要操作。因此任意初始值都可以到达所有出现过的第一 mex，所以：

base≥max⁡ubase\ge \max ubase≥maxu

如果某个点 uuu 的出度至少为 222，说明有两个不同的序列都以 uuu 为第一 mex。此时可以先使用其中一个序列把任意初始值变成 uuu，再使用另一个序列从 uuu 沿图继续走，因此：

out[u]≥2⇒base≥dp[u]out[u]\ge2\Rightarrow base\ge dp[u]out[u]≥2⇒base≥dp[u]

最终，对于初始值 kkk：

f(k)=max⁡(k,base,dp[k])f(k)=\max(k,base,dp[k])f(k)=max(k,base,dp[k])

其中：

  • kkk 表示不进行任何操作；
  • basebasebase 表示任意初始值都能使用的全局方案；
  • dp[k]dp[k]dp[k] 表示初始值本来就是 kkk 时，可以直接沿图向后转移。

设所有第二 mex 的最大值为 mxmxmx。当 k>mxk>mxk>mx 时，任何操作都会把 kkk 变成不超过 mxmxmx 的值，因此最优策略是不操作：

f(k)=kf(k)=kf(k)=k

所以只需要枚举 000 到 min⁡(m,mx)\min(m,mx)min(m,mx)，剩余部分使用等差数列求和即可。

CF2003D1 Turtle and a MEX Problem (Easy Version)

题目描述

这两个版本是不同的问题。在本题版本中，你可以多次选择相同的整数。只有当两个版本都被解决时，你才能进行 hack。

一天，Turtle 正在玩 nnn 个序列。第 iii 个序列的长度为 lil_ili​，那么第 iii 个序列为 ai,1,ai,2,…,ai,lia_{i, 1}, a_{i, 2}, \ldots, a_{i, l_i}ai,1​,ai,2​,…,ai,li​​。

Piggy 在 Turtle 玩耍时给了他一个问题。问题的描述如下：

  • 一开始有一个非负整数 xxx。Turtle 可以对该整数执行任意次数（可能为零次）操作。
  • 每次操作中，Turtle 可以选择一个整数 iii，满足 1≤i≤n1 \le i \le n1≤i≤n，并将 xxx 设为 mex†(x,ai,1,ai,2,…,ai,li)\text{mex}^{\dagger}(x, a_{i, 1}, a_{i, 2}, \ldots, a_{i, l_i})mex†(x,ai,1​,ai,2​,…,ai,li​​)。
  • Turtle 被要求找出答案，即经过任意次数操作后 xxx 的最大值。

Turtle 很容易地解决了上述问题。他定义 f(k)f(k)f(k) 为初始值为 kkk 时上述问题的答案。

随后 Piggy 给了 Turtle 一个非负整数 mmm，并要求 Turtle 求出 ∑i=0mf(i)\sum\limits_{i = 0}^m f(i)i=0∑m​f(i) 的值（即 f(0)+f(1)+…+f(m)f(0) + f(1) + \ldots + f(m)f(0)+f(1)+…+f(m)）。不幸的是，他无法解决这个问题。请你帮助他！

†mex(c1,c2,…,ck)^{\dagger}\text{mex}(c_1, c_2, \ldots, c_k)†mex(c1​,c2​,…,ck​) 定义为在序列 ccc 中没有出现的最小非负整数。例如，mex(2,2,0,3)=1\text{mex}(2, 2, 0, 3) = 1mex(2,2,0,3)=1，mex(1,2)=0\text{mex}(1, 2) = 0mex(1,2)=0。

输入格式

每个测试包含多个测试用例。第一行包含测试用例数 ttt（1≤t≤1041 \le t \le 10^41≤t≤104）。接下来是每个测试用例的描述。

每个测试用例的第一行包含两个整数 n,mn, mn,m（1≤n≤2⋅105,0≤m≤1091 \le n \le 2 \cdot 10^5, 0 \le m \le 10^91≤n≤2⋅105,0≤m≤109）。

接下来的 nnn 行，每行包含若干整数。第一个整数 lil_ili​（1≤li≤2⋅1051 \le l_i \le 2 \cdot 10^51≤li​≤2⋅105）表示第 iii 个序列的长度，接下来的 lil_ili​ 个整数 ai,1,ai,2,…,ai,lia_{i, 1}, a_{i, 2}, \ldots, a_{i, l_i}ai,1​,ai,2​,…,ai,li​​（0≤ai,j≤1090 \le a_{i, j} \le 10^90≤ai,j​≤109）表示第 iii 个序列的元素。

保证所有测试用例中 nnn 的总和不超过 2⋅1052 \cdot 10^52⋅105，所有测试用例中 ∑li\sum l_i∑li​ 的总和不超过 2⋅1052 \cdot 10^52⋅105。

输出格式

对于每个测试用例，输出一个整数——∑i=0mf(i)\sum\limits_{i = 0}^m f(i)i=0∑m​f(i) 的值。

思路

对于每个序列，求出它的前两个缺失非负整数，记为 uuu 和 vvv。

使用该序列时：

  • 若当前 x≠ux\ne ux​=u，操作后 xxx 变为 uuu；
  • 若当前 x=ux=ux=u，操作后 xxx 变为 vvv。

D1 中同一个序列可以重复使用，因此无论初始值是多少，都可以连续使用同一个序列两次：

x→u→vx\rightarrow u\rightarrow vx→u→v

所以任意初始值都能到达每个序列的第二 mex。

令所有序列的第二 mex 最大值为 mxmxmx，那么对于初始值 kkk：

f(k)=max⁡(k,mx)f(k)=\max(k,mx)f(k)=max(k,mx)

其中保留 kkk 表示不进行操作，到达 mxmxmx 表示选择对应序列并重复使用。

因此答案为：

∑k=0mmax⁡(k,mx)\displaystyle \sum_{k=0}^{m}\max(k,mx)k=0∑m​max(k,mx)

若 m≤mxm\le mxm≤mx，则所有 f(k)f(k)f(k) 都等于 mxmxmx：

ans=(m+1)×mxans=(m+1)\times mxans=(m+1)×mx

若 m>mxm>mxm>mx，则前 mx+1mx+1mx+1 项均为 mxmxmx，剩余部分保持原值：

ans=(mx+1)×mx+∑k=mx+1mkans=(mx+1)\times mx+\displaystyle\sum_{k=mx+1}^{m}kans=(mx+1)×mx+k=mx+1∑m​k

后半部分使用等差数列求和即可。

求一个长度为 lll 的序列的前两个 mex 时，只需要标记 000 到 l+1l+1l+1，因为前两个 mex 一定不会超过 l+1l+1l+1。

总时间复杂度为 O(∑li)O(\sum l_i)O(∑li​)。

题目描述

这是题目的简化版本。这两种题目的区别在于对于 mmm 的限制及在简化版本中，满足 ri<li+1r_i < l_{i + 1}ri​<li+1​ 对于每个 iii 从 111 到 m−1m-1m−1。只有当两个版本的问题都被解决后，才可以进行 hack。

max⁡i=1mai<min⁡i=1mbi\max\limits_{i = 1}^m a_i < \min\limits_{i = 1}^m b_i i=1maxm​ai​<i=1minm​bi​

每组数据包含多个测试用例。第一行是测试用例的数量 ttt（1≤t≤1031 \le t \le 10^31≤t≤103）。每个测试用例的描述如下。

对于每个测试用例，第一行有两个整数 n,mn, mn,m（2≤n≤5⋅103,0≤m≤n22 \le n \le 5 \cdot 10^3, 0 \le m \le \frac{n}{2}2≤n≤5⋅103,0≤m≤2n​），分别表示排列的长度和区间的数量。

  • rir_iri​ 一定属于右半部分。

而题目要求所有区间左半部分的元素都小于所有区间右半部分的元素，因此一定有：

CF2003F Turtle and Three Sequences

题目描述

小猪给了小乌龟 3 个长度为 n (1≤n≤3000)n \ (1 \le n\le3000)n (1≤n≤3000) 的序列 a,b,ca,b,ca,b,c，乌龟要在 1∼n1\sim n1∼n 中选出 m (1≤m≤5)m \ (1 \le m ≤ 5)m (1≤m≤5) 个下标 p1∼pmp_1 \sim p_mp1​∼pm​，满足如下条件：

  • ppp 是 1∼n1\sim n1∼n 的子序列。

  • $\forall 1\le i < m, a\large_{p_i} \small \normalsize\le a\large_{p_{i+1}} $，即得到的 aaa 序列严格不降。

  • ∀1≤i,j≤m (i≠j),bpi≠bpj\forall 1\le i, j\le m \ (i\ne j), b\large_{p_i}\normalsize \ne b\large_{p_j}∀1≤i,j≤m (i​=j),bpi​​​=bpj​​ ，即得到的 bbb 序列两两不同。

输入格式

第二、三、四行 nnn 个正整数 分别表示 a,b,ca,b,ca,b,c 三个序列，其中 1≤ai,bi≤n1\le a_i, b_i\le n1≤ai​,bi​≤n，1≤ci≤1041\le c_i\le 10^41≤ci​≤104。

输出格式

思路

由于 m≤5m\le 5m≤5，可以使用随机染色。

将每一种 bbb 的取值随机染成 mmm 种颜色之一，用一个二进制位表示颜色。相同的 bbb 值访问的是同一个颜色，因此一定会被染成相同颜色。

如果选出的 mmm 个位置颜色两两不同，那么它们的 bbb 值也一定两两不同。不同的 bbb 值可能被染成相同颜色，因此单次染色可能漏掉最优解，重复随机染色若干次即可大幅降低错误概率。

color=col[bi]color=col[b_i] color=col[bi​]

premask=mask⊕colorpremask=mask\oplus color premask=mask⊕color
