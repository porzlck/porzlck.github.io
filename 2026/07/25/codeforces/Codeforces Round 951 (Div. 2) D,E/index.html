CF1979D Fixing a Binary String

题目描述

给定一个长度为 nnn 的二进制字符串 sss，仅包含 000 和 111。你可以恰好执行一次如下操作：

  1. 选择一个整数 ppp（1≤p≤n1 \le p \le n1≤p≤n）。
  2. 翻转子串 s1s2…sps_1 s_2 \ldots s_ps1​s2​…sp​。此步骤后，字符串 s1s2…sns_1 s_2 \ldots s_ns1​s2​…sn​ 变为 spsp−1…s1sp+1sp+2…sns_p s_{p-1} \ldots s_1 s_{p+1} s_{p+2} \ldots s_nsp​sp−1​…s1​sp+1​sp+2​…sn​。
  3. 然后，将字符串 sss 向左循环移动 ppp 次。此步骤后，原始字符串 s1s2…sns_1s_2 \ldots s_ns1​s2​…sn​ 变为 sp+1sp+2…snspsp−1…s1s_{p+1}s_{p+2} \ldots s_n s_p s_{p-1} \ldots s_1sp+1​sp+2​…sn​sp​sp−1​…s1​。

例如，对字符串 110001100110 选择 p=3p=3p=3 执行操作，第二步后字符串变为 011001100110，第三步后变为 001100110011。

一个字符串 sss 被称为 kkk-proper，当且仅当满足以下两个条件：

  • s1=s2=…=sks_1=s_2=\ldots=s_ks1​=s2​=…=sk​；
  • 对于任意 iii（1≤i≤n−k1 \le i \le n - k1≤i≤n−k），都有 si+k≠sis_{i+k} \neq s_isi+k​​=si​。

例如，当 k=3k=3k=3 时，字符串 000、111000111 和 111000 是 kkk-proper 的，而 000000、001100 和 1110000 不是。

给定一个整数 kkk，且 kkk 是 nnn 的约数。请你找到一个整数 ppp（1≤p≤n1 \le p \le n1≤p≤n），使得经过上述操作后，字符串 sss 变为 kkk-proper，或者判断是否不可能实现。注意，即使字符串初始时已经是 kkk-proper，也必须恰好执行一次操作。

每组测试用例的第二行包含一个长度为 nnn 的二进制字符串 sss，仅包含字符 000 和 111。

保证所有测试用例中 nnn 的总和不超过 2⋅1052 \cdot 10^52⋅105。

CF1979E Manhattan Triangle

题目描述

曼哈顿距离定义为两个点 $ (x_1, y_1) $ 和 $ (x_2, y_2) $ 之间的距离：$ |x_1 - x_2| + |y_1 - y_2| $。

我们称平面上任意三点为“曼哈顿三角形”，当且仅当这三点两两之间的曼哈顿距离都相等。

给定一组两两不同的点，以及一个偶数整数 $ d $，你的任务是从给定的点集中找出任意一个曼哈顿三角形，使得三角形的三个顶点两两之间的曼哈顿距离均为 $ d $。

输入格式

每组测试数据包含多个测试用例。第一行包含一个整数 $ t （（（ 1 \le t \le 10^4 $），表示测试用例的数量。

每个测试用例的第一行包含两个整数 $ n $ 和 $ d （（（ 3 \le n \le 2 \cdot 10^5 ，，， 2 \le d \le 4 \cdot 10^5 ，，， d $ 为偶数），分别表示点的数量和要求的曼哈顿距离。

接下来的 $ n $ 行，每行包含两个整数 $ x_i $ 和 $ y_i （（（ -10^5 \le x_i, y_i \le 10^5 $），表示第 $ i $ 个点的坐标。保证所有点两两不同。

保证所有测试用例中 $ n $ 的总和不超过 $ 2 \cdot 10^5 $。

输出格式

对于每个测试用例，输出三个不同的整数 $ i, j, k （（（ 1 \le i, j, k \le n $），表示构成曼哈顿三角形的三个点的编号。如果不存在满足条件的曼哈顿三角形，输出 “0 0 0”（不带引号）。

如果有多组解，输出任意一组均可。

思路

将每个点 (x,y)(x,y)(x,y) 变换为：

u=x+y,v=x−yu=x+y,\quad v=x-y u=x+y,v=x−y

此时曼哈顿距离转化为切比雪夫距离：

∣x1−x2∣+∣y1−y2∣=max⁡(∣u1−u2∣, ∣v1−v2∣)|x_1-x_2|+|y_1-y_2| = \max(|u_1-u_2|,\ |v_1-v_2|) ∣x1​−x2​∣+∣y1​−y2​∣=max(∣u1​−u2​∣, ∣v1​−v2​∣)

若三个点两两距离均为 ddd，则一定存在两个点同行或同列，且另一维坐标相差 ddd。

先检查同列情况。枚举点：

A=(u,v)A=(u,v) A=(u,v)

查找是否存在：

B=(u,v+d)B=(u,v+d) B=(u,v+d)

第三个点必须位于左右相距 ddd 的列上：

C=(u−d,w)或C=(u+d,w)C=(u-d,w)\quad \text{或}\quad C=(u+d,w) C=(u−d,w)或C=(u+d,w)

并满足：

v≤w≤v+dv\le w\le v+d v≤w≤v+d

此时三点两两切比雪夫距离均为 ddd。

用 pos[{u,v}] 判断具体坐标是否存在，用 mp[u] 保存同一列的所有 (v,id)。将每列按照 vvv 排序，通过 lower_bound 判断区间 [v,v+d][v,v+d][v,v+d] 内是否有第三个点。

若没有找到，则交换所有点的 u,vu,vu,v，再检查一次，相当于处理原来的同行情况。

时间复杂度为：

O(nlog⁡n)O(n\log n) O(nlogn)
