Codeforces Round 1045 (Div.2) D

发表于2026-07-29|更新于2026-07-29|算法
|浏览量:

题目描述

给定一棵包含 nnn 个顶点的树（编号从 111 到 nnn）。你可以按如下多步操作（称为滑动操作）来修改其结构：

  1. 选择三个不同的顶点 aaa、bbb、ccc，其中 bbb 直接和 aaa、ccc 相连。
  2. 对于 bbb 的所有邻居 ddd（不包括 aaa 和 ccc），移除 bbb 和 ddd 之间的边，并将 ddd 直接与 ccc 相连。

例如，下图展示了在最左侧的树中，a=4a = 4a=4，b=3b = 3b=3，c=5c = 5c=5 时的这一操作。

可以证明，经过一次滑动操作后，得到的图仍然是一棵树。

你的任务是找到一系列滑动操作，使树最终转变为一条路径图，并且操作次数最少。如果至少需要一次操作，则只需输出最优方案中的第一次滑动操作。可以证明，一定可以用有限步操作将树变为一条路径图。

注：
∗^{\ast}∗ 一棵树是一个无环连通图。
†^{\dagger}† 路径图是每个顶点的度数都不超过 222 的树。注意，只有一个顶点且没有边的图也算作路径图。

输入格式

每组测试数据包含多组测试用例。
第一行为测试用例个数 ttt（1≤t≤1041 \le t \le 10^41≤t≤104）。每组测试用例描述如下：

第一行包含一个整数 nnn（1≤n≤2⋅1051 \le n \le 2 \cdot 10^51≤n≤2⋅105），表示树的顶点数。

接下来 n−1n-1n−1 行，每行包含两个整数 uiu_iui​ 和 viv_ivi​（1≤ui,vi≤n1 \le u_i, v_i \le n1≤ui​,vi​≤n，ui≠viu_i \ne v_iui​​=vi​），表示树中的一条边。

保证给定的边能构成一棵树。

保证所有测试用例的 nnn 之和不超过 2×1052 \times 10^52×105。

输出格式

对于每个测试用例：

  • 如果不需要任何操作（即输入树本身就是一条路径图），输出 −1-1−1。
  • 否则，输出第一次滑动操作选择的三个不同顶点 aaa、bbb、ccc（1≤a,b,c≤n1 \le a, b, c \le n1≤a,b,c≤n）。

如果存在多种合法的第一次操作，你可以输出其中任意一种。

思路

设当前树的直径长度为 DDD。

最终要把树变成一条包含所有 nnn 个点的链，因此最终直径长度为 n−1n-1n−1。

一次滑动操作中，节点之间的距离最多只会增加 111，所以树的直径一次最多增加 111。因此，至少需要

n−1−Dn-1-D n−1−D

次操作。

所以只要找到一种操作，能够让当前直径恰好增加 111，那么这次操作就一定可以作为某个最优方案的第一步。

先用两次 DFS 找树的直径：

  • 第一次从 111 出发，找到最远点 ststst；
  • 第二次从 ststst 出发，找到最远点 ededed。

那么 ststst 到 ededed 的路径就是树的一条直径。

第二次 DFS 时记录每个点的父节点 f[x]f[x]f[x]，从 ededed 不断执行

就能沿着直径走回 ststst。将这条路径上的所有点标记。

如果直径长度满足

D=n−1D=n-1 D=n−1

说明所有点都已经在同一条链上，直接输出 -1。

否则，从直径端点 ededed 开始沿父节点向上走，找到第一个存在非直径邻居的点 uuu。

设：

  • f[u]f[u]f[u] 是 uuu 在直径上的父节点；
  • vvv 是 uuu 的一个非直径邻居。
