Educational Codeforces Round 195 (Rated for Div.2) F (挺有思维含量的博弈论 + DP)

发表于2026-11-02|更新于2026-11-02|算法
|浏览量:

Alice and Bob are playing a game. They have a permutation ppp of length nnn — an array of nnn elements in which every integer from 111 to nnn occurs exactly once. Initially, every element of the permutation is colored white.

The players take turns; Alice goes first. On each turn, the current player chooses between 111 and kkk white elements and colors all of them either red or blue. All elements chosen on the same turn must receive the same color.

The game ends when there are no white elements left. If the resulting permutation can be sorted in increasing order by swapping elements of the same color, Alice wins. Otherwise, Bob wins. Any two elements may be swapped as long as they have the same color.

Determine who wins if both players play optimally.

Input

The first line contains one integer ttt (1≤t≤1041 \le t \le 10^41≤t≤104) — the number of test cases.

Each test case consists of two lines:

  • the first line contains two integers nnn and kkk (2≤n≤2⋅1052 \le n \le 2 \cdot 10^52≤n≤2⋅105; 1≤k≤min⁡(20,n)1 \le k \le \min(20, n)1≤k≤min(20,n)) — the length of the permutation and the maximum number of elements that can be colored in one turn;
  • the second line contains nnn pairwise distinct integers p1,p2,…,pnp_1, p_2, \ldots, p_np1​,p2​,…,pn​ (1≤pi≤n1 \le p_i \le n1≤pi​≤n).

Additional constraints on the input:

  • the sum of nnn over all test cases does not exceed 2⋅1052 \cdot 10^52⋅105.

Output

For each test case, print Alice on a separate line if Alice wins, or Bob if Bob wins.

思路

将排列分解为置换环，环长降序排序。由于同一个环必须染成同一种颜色，因此只需要考虑环长。

1. k=1k=1k=1

  • 最大环长 ≥3\ge 3≥3，Bob 必胜。
  • 最大环长 =1=1=1，Alice 必胜。
  • 否则根据 nnn 的奇偶性判断，奇数 Alice，偶数 Bob。

2. 最大环长 >k+1>k+1>k+1

Bob 必胜，因为 Alice 无法一次染完整个环。

3. 最大环长 =k+1=k+1=k+1

如果存在两个长度为 k+1k+1k+1 的环，Bob 必胜。

否则，Alice 第一回合必须染完其他所有长度大于 111 的环。

设这些环的长度和为 sumsumsum，单点环数量为 cntcntcnt。

为了让 Bob 先操作大环，Alice 还需要染掉 cnt mod (k+1)cnt\bmod(k+1)cntmod(k+1) 个单点环。

因此：

nd=sum+cnt mod (k+1)nd=sum+cnt\bmod(k+1) nd=sum+cntmod(k+1)

若 1≤nd≤k1\le nd\le k1≤nd≤k，Alice 必胜，否则 Bob 必胜。

4. 最大环长 ≤k\le k≤k

使用三维 DP。

Alice 第一回合选择若干个完整的环，总长度不能超过 kkk。

Bob 会在剩余最大的 kkk 个环中各染一个元素，Alice 需要补染的数量为 ∑(ai−1)\sum(a_i-1)∑(ai​−1)。

因此只需找到一种方案，使该值不超过 kkk。

Alice 最多染掉 kkk 个环，所以只需要考虑前 2k2k2k 个环。

定义 dp[i][j][c]dp[i][j][c]dp[i][j][c] 表示考虑前 iii 个环，使用 jjj 个元素，染完 ccc 个环时的最小补染数量。

对于当前环 aia_iai​：

  • 选择：dp[i+1][j+ai][c+1]←dp[i][j][c]dp[i+1][j+a_i][c+1]\gets dp[i][j][c]dp[i+1][j+ai​][c+1]←dp[i][j][c]。
  • 不选：dp[i+1][j][c]←dp[i][j][c]+(i−c<k ? ai−1:0)dp[i+1][j][c]\gets dp[i][j][c]+(i-c<k\ ?\ a_i-1:0)dp[i+1][j][c]←dp[i][j][c]+(i−c<k ? ai​−1:0)。

所有转移取最小值。

最后若存在 1≤j≤k1\le j\le k1≤j≤k，使得 dp[m][j][c]≤kdp[m][j][c]\le kdp[m][j][c]≤k，则 Alice 必胜，否则 Bob 必胜。

时间复杂度：O(nlog⁡n+k3)O(n\log n+k^3)O(nlogn+k3)。
