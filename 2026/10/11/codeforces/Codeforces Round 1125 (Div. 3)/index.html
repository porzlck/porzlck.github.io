CF2275D Precision Alignment

题目描述

K1o0n volunteered to work as a teaching assistant in the physics department, and he was assigned n n n training laboratories. In the i i i -th laboratory, there are three instruments; their readings are ai a_i ai​ , bi b_i bi​ , and ci c_i ci​ . The instruments are distinguishable, and the order in this triple is fixed: the first ( ai a_i ai​ ), the second ( bi b_i bi​ ), the third ( ci c_i ci​ ).

One action is to choose the index of a laboratory i i i and perform exactly one of the three adjustments:

  • ci+=sgn⁡(ai−bi) c_i \mathrel{+}= \operatorname{sgn}(a_i - b_i) ci​+=sgn(ai​−bi​)
  • bi+=sgn⁡(ai−ci) b_i \mathrel{+}= \operatorname{sgn}(a_i - c_i) bi​+=sgn(ai​−ci​)
  • ai+=sgn⁡(bi−ci) a_i \mathrel{+}= \operatorname{sgn}(b_i - c_i) ai​+=sgn(bi​−ci​)

Here sgn⁡(x) \operatorname{sgn}(x) sgn(x) equals 1 1 1 if x>0 x \gt 0 x>0 , equals −1 -1 −1 if x<0 x \lt 0 x<0 , and equals 0 0 0 if x=0 x = 0 x=0 .

In other words, an adjustment shifts the reading of one instrument by one unit, and the direction of the shift is determined by the difference of the readings of the other two, taken in the order they are written: the earlier one minus the later one.

The actions are performed one after another, and each adjustment looks at the readings that have been obtained by that moment. The same laboratory may be adjusted any number of times, and some may be left untouched altogether; in total, K1o0n is ready to make at most k k k actions across all laboratories.

The work will be evaluated by the worst laboratory:

S=min⁡1≤i≤n(ai+bi+ci),S = \min_{1 \le i \le n} (a_i + b_i + c_i), S=1≤i≤nmin​(ai​+bi​+ci​),

where the readings are taken after all actions. K1o0n wants to impress his colleagues, so he asks you to find the maximum S S S he can achieve.

输入格式

The first line contains an integer t t t ( 1≤t≤104 1 \le t \le 10^4 1≤t≤104 ) — the number of testcases.

The first line of each testcase contains two integers n n n and k k k ( 1≤n≤2⋅105 1 \le n \le 2 \cdot 10^5 1≤n≤2⋅105 , 0≤k≤1018 0 \le k \le 10^{18} 0≤k≤1018 ) — the number of laboratories and the maximum number of actions.

The next n n n lines of each testcase contain three integers ai a_i ai​ , bi b_i bi​ , and ci c_i ci​ ( −109≤ai,bi,ci≤109 -10^9 \le a_i, b_i, c_i \le 10^9 −109≤ai​,bi​,ci​≤109 ).

输出格式

For each testcase, output one integer — the maximum achievable value of S S S .

Note that the answer may not fit into a 32-bit integer type. Use a 64-bit integer type (long long in C++, long in Java).

The old roads are arranged as follows:

  • buildings ai a_i ai​ and bi b_i bi​ are connected by a road;
  • buildings ai a_i ai​ and bi+1 b_{i+1} bi+1​ ( i+1≤n i + 1 \le n i+1≤n ) are connected by a road;
  • buildings ai a_i ai​ and bi−1 b_{i-1} bi−1​ ( 2≤i 2 \le i 2≤i ) are connected by a road.

All old roads are bidirectional. There are no other available roads in the city.

A road between buildings of the same company has length 2 2 2 kilometers. A road between buildings of different companies has length 1 1 1 kilometer.

K1o0n decided to personally drive around the city and assess the consequences of his friend's mischief. He starts at building a1 a_1 a1​ and wants to visit each of the 2n 2n 2n buildings exactly once. He may finish the trip at any building.

输入格式

The second line of each testcase contains n n n integers a1,a2,…,an a_1, a_2, \ldots, a_n a1​,a2​,…,an​ ( 1≤ai≤109 1 \le a_i \le 10^9 1≤ai​≤109 ) — the buildings on the first main road.

CF2275F Tea Blend

题目描述

Recently, K1o0n made an impulsive purchase of n n n packs of tea and is now wondering when he will manage to try all the blends. He is picky about tea, so he immediately assigned each pack a strength — an integer ai a_i ai​ .

The packs are arranged on the shelf in the order they were bought, and K1o0n is too lazy to sort them out: when brewing tea, he pours the first j j j packs in order into the teapot, and then adds one more spoon from the pack with number i i i . Count how many capricious blends K1o0n can brew, that is, how many pairs (i,j) (i, j) (i,j) with 1≤i≤n 1 \le i \le n 1≤i≤n and 1≤j≤n 1 \le j \le n 1≤j≤n give an odd number of natural divisors of the number F(i,j) F(i, j) F(i,j) .

输入格式

The first line contains an integer t t t ( 1≤t≤104 1 \le t \le 10^4 1≤t≤104 ) — the number of testcases.

The first line of each testcase contains an integer n n n ( 1≤n≤2⋅105 1 \le n \le 2 \cdot 10^5 1≤n≤2⋅105 ) — the number of tea packs.

The second line of each testcase contains n n n integers a1,a2,…,an a_1, a_2, \ldots, a_n a1​,a2​,…,an​ ( 1≤ai≤106 1 \le a_i \le 10^6 1≤ai​≤106 ) — the strengths of the teas.

It is guaranteed that the sum of n n n over all testcases does not exceed 2⋅105 2 \cdot 10^5 2⋅105 .

输出格式

Note that the answer may not fit into a 32-bit type. Use a 64-bit type (long long in C++, long in Java).

一个正整数的约数个数为奇数，当且仅当它是完全平方数。

因此题目等价于统计满足
