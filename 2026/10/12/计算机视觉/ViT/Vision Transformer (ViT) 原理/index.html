Vision Transformer (ViT) 原理

|浏览量:

把图片切成 Patch

把 Patch 变成向量

Transformer 不能直接接收一个二维的矩阵作为普通 Token,所以就需要把每个 Patch 展平，也就是 Flatten 操作。

例如：
P1=[1256] P_1= \begin{bmatrix} 1&2\\ 5&6 \end{bmatrix} P1​=[15​26​]

变成：
p1=[1,2,5,6] p_1=[1,2,5,6] p1​=[1,2,5,6]

最后，整张图片就变成了一个序列：
Xpatch=[12563478910131411121516] X_{\mathrm{patch}}= \begin{bmatrix} 1&2&5&6\\ 3&4&7&8\\ 9&10&13&14\\ 11&12&15&16 \end{bmatrix} Xpatch​=​13911​241012​571315​681416​​

这个例子得到的是一个 4*4 的矩阵，第一个4代表了 Patch 数量，第二个 4 代表了每个 Patch 向量的长度。

Patch Embedding

Patch Embedding 其实有两个操作，第一个是思想二的 Flatten,第二个也是比较关键的，我阅读了网上一些讲解 Vit 的文章，很多都没有特意提到，也就是 Linear Projection 操作。

zi=xiW+b z_i=x_iW+b zi​=xi​W+b

其中：
xi∈R768 x_i\in\mathbb{R}^{768} xi​∈R768

W∈R768×D W\in\mathbb{R}^{768\times D} W∈R768×D

最终：
zi∈RD z_i\in\mathbb{R}^{D} zi​∈RD

DDD 是我们选择的 Transformer 隐藏维度，不要求必须等于 768。

Position Embedding

前面通过 Patch Embedding，我们已经把图片转换成了一个个 Token，但是还有一个问题，就是这些 Token 并没有包含位置信息。

比如一张图片被切成了 4 个 Patch，我们知道哪个 Patch 在左上角，哪个在右下角，但是 Transformer 的 Self-Attention 本身并不知道这些信息。

所以这里就需要用到 Position Embedding，也就是位置编码。

它的操作其实很简单，就是给每个 Token 加上一个对应的位置向量。

例如，假设某个 Token 是：

P1=[1,2,3]P_1=[1,2,3] P1​=[1,2,3]

它对应的位置向量是：

E1=[0.1,0.2,0.3]E_1=[0.1,0.2,0.3] E1​=[0.1,0.2,0.3]

那么相加后：

P1′=P1+E1=[1.1,2.2,3.3]P'_1=P_1+E_1=[1.1,2.2,3.3] P1′​=P1​+E1​=[1.1,2.2,3.3]

其他 Token 也是一样的操作。

所以 Position Embedding 可以表示为：

X′=X+EposX'=X+E_{pos} X′=X+Epos​

这里是直接相加，并不会改变原来 Token 的维度。

原始 ViT 使用的是可学习的位置编码，也就是这些位置向量的值不是固定的，而是通过训练得到的。

另外需要注意的是，ViT 在添加 Position Embedding 之前，还会先添加 CLS Token，所以位置编码也需要给 CLS 留一个位置。

假设前面经过 Patch Embedding 得到了 196 个 Token，每个 Token 的维度为 768，添加 CLS 后就变成了 197 个 Token。

因此位置编码的维度为：

Epos∈R197×768E_{pos}\in\mathbb{R}^{197\times768} Epos​∈R197×768

最后直接将两者相加：

Z0=[CLS;P1;P2;…;P196]+EposZ_0=[CLS;P_1;P_2;\ldots;P_{196}]+E_{pos} Z0​=[CLS;P1​;P2​;…;P196​]+Epos​

得到的结果仍然是：

Z0∈R197×768Z_0\in\mathbb{R}^{197\times768} Z0​∈R197×768

这样 Transformer 在处理这些 Token 时，就可以利用它们对应的位置信息了。

CLS Token

CLS Token是人为添加的一个特殊向量，一开始只是一个可学习的向量，没有信息，通过 Self-Attention 机制获取图片信息。

CLS 一开始也不知道要收集什么信息，是训练出来的。

假设我们训练一个猫狗分类模型：

  1. 输入一张猫的图片。
  2. CLS 通过 Transformer 与其他 Patch 交互。
  3. 取最终 CLS 向量，通过分类层预测猫或狗。
  4. 如果预测错了，计算 Loss，并通过反向传播更新 CLS 参数、注意力层等参数。
  5. 重复训练大量图片。

当然，CLS也不是必须的，有通过对所有Patch Token取平均的操作，叫Global Average Pooling。

Self-attention

前面的操作得到了一个个 Token，但是这些 Token 之间还没有进行信息交互。Self-Attention 的作用就是让每个 Token 能够获取其他 Token 的信息。

我这里就搞一个小例子。

假设现在只有三个 Token，分别是 CLS、Patch1 和 Patch2，每个 Token 的维度都是 2：

X=[002004]X= \begin{bmatrix} 0&0\\ 2&0\\ 0&4 \end{bmatrix} X=​020​004​​

Self-Attention 首先通过三个不同的线性变换得到 Q、K、V：

Q=XWQ,K=XWK,V=XWVQ=XW_Q,\quad K=XW_K,\quad V=XW_V Q=XWQ​,K=XWK​,V=XWV​

其中，Q（Query）用来查询信息，K（Key）用来计算相关性，V（Value）则是实际要传递的信息。

为了方便计算，这里假设三个权重矩阵都是单位矩阵：

WQ=WK=WV=IW_Q=W_K=W_V=I WQ​=WK​=WV​=I

因此：

Q=K=V=XQ=K=V=X Q=K=V=X

第一步：计算注意力分数

这里我们只看 CLS 是怎么获取其他 Patch 信息的。

CLS 的 Query 为：

QCLS=[0,0]Q_{CLS}=[0,0] QCLS​=[0,0]

分别与三个 Token 的 Key 做点积：

QCLSKT=[0,0,0]Q_{CLS}K^T=[0,0,0] QCLS​KT=[0,0,0]

第二步：计算注意力权重

先将分数除以 dk\sqrt{d_k}dk​​，这里 dk=2d_k=2dk​=2，然后经过 Softmax：

ACLS=Softmax⁡([0,0,0]2)A_{CLS}=\operatorname{Softmax} \left(\frac{[0,0,0]}{\sqrt{2}}\right) ACLS​=Softmax(2​[0,0,0]​)

得到：

ACLS=[13,13,13]A_{CLS}=\left[\frac13,\frac13,\frac13\right] ACLS​=[31​,31​,31​]

也就是说，CLS 对三个 Token 分配了相同的注意力权重。

第三步：对 Value 加权求和

根据刚才得到的注意力权重，对三个 Token 的 Value 进行加权求和：

OCLS=13[0,0]+13[2,0]+13[0,4]O_{CLS}=\frac13[0,0]+\frac13[2,0]+\frac13[0,4] OCLS​=31​[0,0]+31​[2,0]+31​[0,4]

最终得到：

OCLS=[23,43]O_{CLS}=\left[\frac23,\frac43\right] OCLS​=[32​,34​]

可以看到，CLS 原本是一个全零向量，但是经过 Self-Attention 后，就获得了其他 Patch 的信息。

这里只计算了 CLS 的注意力输出，实际上其他 Patch 也会进行同样的操作。

将整个过程写成公式就是：

Attention⁡(Q,K,V)=Softmax⁡(QKTdk)V\operatorname{Attention}(Q,K,V)= \operatorname{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V Attention(Q,K,V)=Softmax(dk​​QKT​)V

其中，QKTQK^TQKT 用来计算 Token 之间的相关性，除以 dk\sqrt{d_k}dk​​ 是为了避免点积过大，使 Softmax 的结果过于集中，最后通过 V 的加权求和完成信息交互。

需要注意的是，实际 ViT 中的 Q、K、V 是通过不同的可学习矩阵得到的，并不直接等于 X，而且输入还包含位置编码。上面的例子只是为了方便理解计算过程。

Multi-Head Self-Attention

前面讲的是单头 Self-Attention，但是实际 ViT 使用的是 Multi-Head Self-Attention，也就是多头自注意力。

它的思想也很简单，就是让多个 Attention Head 分别学习 Token 之间的关系，最后再将结果合并。

例如 ViT-Base 中，每个 Token 的维度是 768，一共有 12 个 Head，那么每个 Head 的维度就是：

dhead=76812=64d_{head}=\frac{768}{12}=64 dhead​=12768​=64

需要注意的是，并不是将 197 个 Token 分给 12 个 Head，而是每个 Head 都能处理全部 197 个 Token，只不过每个 Head 的 Q、K、V 都是通过各自的线性投影得到的，维度为 64。

每个 Head 独立计算 Self-Attention：

headi=Attention⁡(Qi,Ki,Vi)head_i=\operatorname{Attention}(Q_i,K_i,V_i) headi​=Attention(Qi​,Ki​,Vi​)

每个 Head 的输出维度为：

headi∈R197×64head_i\in\mathbb{R}^{197\times64} headi​∈R197×64

然后将 12 个 Head 的结果拼接起来：

197×(12×64)=197×768197\times(12\times64)=197\times768 197×(12×64)=197×768

最后再经过一个 Linear 层：

MultiHead⁡(X)=Concat⁡(head1,…,head12)WO\operatorname{MultiHead}(X)= \operatorname{Concat}(head_1,\ldots,head_{12})W_O MultiHead(X)=Concat(head1​,…,head12​)WO​

这样输出维度仍然是 197×768197\times768197×768。

多头注意力的好处就是不同的 Head 可以学习不同的特征关系，比只使用一个 Head 更灵活。

LayerNorm & Residual Connection

归一化和残差连接，这个就不展开说了。

MLP

经过 Multi-Head Self-Attention 后，不同 Token 之间已经进行了信息交互，接下来会通过 MLP 进一步处理特征。

ViT 中的 MLP 主要由两个 Linear 层和一个 GELU 激活函数组成。

以 ViT-Base 为例，输入维度为 768，通常先扩大到 3072，再映射回 768：

768→3072→768768\rightarrow3072\rightarrow768 768→3072→768

其中两个 Linear 层之间会使用 GELU 激活函数，引入非线性。

MLP 是对每个 Token 分别进行处理的，不负责 Token 之间的信息交互，这部分主要由 Self-Attention 完成。

完整 Transformer Encoder

首先经过 LayerNorm 和 Multi-Head Self-Attention，然后进行残差连接：

X′=X+MSA⁡(LN⁡(X))X'=X+\operatorname{MSA}(\operatorname{LN}(X)) X′=X+MSA(LN(X))

接下来再经过 LayerNorm 和 MLP，最后进行一次残差连接：

X′′=X′+MLP⁡(LN⁡(X′))X''=X'+\operatorname{MLP}(\operatorname{LN}(X')) X′′=X′+MLP(LN(X′))

这就是 ViT 中一个 Transformer Encoder Block 的计算过程。

对于 ViT-Base，这样的 Block 一共有 12 个。

虽然每个 Block 都会不断更新 Token 的特征，但是输出维度始终保持为：

X∈R197×768X\in\mathbb{R}^{197\times768} X∈R197×768

Classification Head

经过所有 Transformer Encoder Block 后，就得到了更新后的 197 个 Token。

前面介绍 CLS Token 时说过，它的作用就是学习整张图片的分类表示。

所以原始 ViT 会先对 Encoder 的输出进行一次 LayerNorm，然后取第一个 CLS Token：

XCLS∈R768X_{CLS}\in\mathbb{R}^{768} XCLS​∈R768

最后将 CLS Token 送入分类头，得到最终的分类结果。

例如我们要做猫狗分类，那么就可以使用一个 Linear 层，将 768 维映射到 2 维：

768→2768\rightarrow2 768→2

输出的两个数分别对应猫和狗的分类分数，经过 Softmax 就可以转换成对应的概率。
