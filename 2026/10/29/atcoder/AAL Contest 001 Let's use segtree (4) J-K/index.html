J

There is a string SSS of length 101810^{18}1018 consisting of 0 and 1. Let SiS_iSi​ denote the iii-th character of SSS.

Initially, all characters of SSS are 0.

Process QQQ queries. Each query is of one of the following 222 types:

  • 1 l r: Flip Sl,Sl+1,…,SrS_l,S_{l+1},\ldots,S_rSl​,Sl+1​,…,Sr​. That is, change each 0 to 1 and each 1 to 0.

  • 2 l r: Print the number of 1s among Sl,Sl+1,…,SrS_l,S_{l+1},\ldots,S_rSl​,Sl+1​,…,Sr​.

  • 1≤Q≤2×1051 \leq Q \leq 2 \times 10^51≤Q≤2×105

  • 1≤l≤r≤10181 \leq l \leq r \leq 10^{18}1≤l≤r≤1018

  • All numerical values in the input are integers.

挺基础的一道题，我这做法融合离散化，线段树节点保存区间信息。

  • 1 x: Add 111 occurrence of xxx to SSS.
